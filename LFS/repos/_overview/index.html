GitHub repositories relating to VM and their locations on VM

  • Host system NixOS-configs has shell profile for managing VM, including package management shell functions. Specifically 21-lfs.sh, lfs-autobuild.sh, lfs-updates.sh and lfs-vm-bootstrap.sh are the scripts for LFS management.

  • ~/build_duration — contains text files that contain the duration, in seconds, of building each package.

  • ~/lfs_apps — desktop configuration files and shell scripts these desktop files call.

  • ~/lfs_dotfiles — Fastfetch, HyFetch and systemd configuration files for LFS VM.

  • ~/lfs_gnuplot — Gnuplot files for my LFS VM.

  • ~/lfs_packaging — which contains packaging scripts for building custom packages.

  • ~/lfs_scripts — shell scripts (including VM shell profile and scripts called by Executor and Command Output extensions/widgets) used by LFS system.

  • ~/logs — assorted log files from LFS system.

  • /usr/share/gnome-shell/extensions/executor@raujonas.github.io — customized verison of the executor@raujonas.github.io I use under my GNOME session (which is the main session I boot).

  • /var/lib/book-packages — package inventories for LFS and BLFS packages. Now empty as all packages are now provided by custom build scripts.

  • /var/lib/custom-packages — package inventories for custom packages (those in ~/lfs_packaging).
