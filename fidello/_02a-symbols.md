## Mathematical symbols

|        Symbol         | Meaning                       |
|-----------------------|-------------------------------|
| $\def$                | Defined as.                   |
| $\forall$             | For all.                      |
| $\implies$            | Implies or follows.           |
| $\in$                 | Element of.                   |
| $\mathbb{R}$          | Set of all real numbers.      |
| $\mathbb{Z}$          | Set of all integers.          |
| $\mathbb{Z}^{+}$      | Set of all positive integers. |
| $\therefore$          | Therefore.                    |
