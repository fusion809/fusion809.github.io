Partial differentiation

Partial derivatives are just a straightforward extension of derivatives as you understand them already. The key difference is that they are derivatives of multivariable functions instead of single-variable functions. Further, when you differentiate with respect to one variable, all other variables are kept constant. If you would like to build a graphical image of what the partial derivative is, well recall that the derivative of a single-variable function is just the gradient of that function. Consequently, it is also the gradient of the tangent line to that function. The partial derivative is similar to that. As when we have a function with more than a single independent variable, we have the freedom to choose which variable or variables we wish to determine our function's gradient with respect to.

If you want to visualize this, imagine a surface defined by z=f(x,y)z=f(x,y)z=f(x,y) for example. Because a tangent line is two dimensional and we're in three dimensional space, there can be more than one tangent line to a given point. As when constructing the tangent line, we must answer a question: in which direction do we want our line to be tangential to our surface? It could be tangential in the xxx direction or the yyy direction, or even in any arbitrary direction in the xxx-yyy plane. If we want the tangent line in the xxx direction, we will need the partial derivative with respect to xxx to get its gradient, whereas if we want the tangent line in the yyy direction, we will need the partial derivative with respect to yyy to get its gradient. More generally, for an arbitrary direction in the xxx-yyy plane we would use the directional derivative as it is called.

Say fff is a function of two variables — xxx and yyy. Then its partial derivative with respect to xxx is formally defined as:

∂f∂x=lim⁡h→0f(x+h,y)−f(x,y)h.\begin{aligned} \dfrac{\partial f}{\partial x} &= \lim_{h\rightarrow 0} \dfrac{f(x+h, y)-f(x, y)}{h}. \end{aligned}∂x∂f​​=h→0lim​hf(x+h,y)−f(x,y)​.​

This is analogous to the first principles definition of the derivative you would have learned for standard derivatives. Namely, if we are differentiating f(x)f(x)f(x):

dfdx=lim⁡h→0f(x+h)−f(x)h.\begin{aligned} \dfrac{df}{dx} &= \lim_{h\rightarrow 0}\dfrac{f(x+h) - f(x)}{h}. \end{aligned}dxdf​​=h→0lim​hf(x+h)−f(x)​.​

The only difference is that now we also have a variable yyy that our function f(x,y)f(x,y)f(x,y) depends on, but is kept constant when differentiating with respect to xxx. Say f(x,y)=2x2yf(x,y)=2x^2yf(x,y)=2x2y. Then ∂f∂x\dfrac{\partial f}{\partial x}∂x∂f​ would be:

∂f∂x=lim⁡h→02(x+h)2y−2x2yh.\begin{aligned} \dfrac{\partial f}{\partial x} &= \lim_{h\rightarrow 0} \dfrac{2(x+h)^2y - 2x^2y}{h}. \end{aligned}∂x∂f​​=h→0lim​h2(x+h)2y−2x2y​.​

Okay, so that is the long way of finding out partial derivatives. Fortunately, there is also a faster way. Which is that we apply normal differentiation rules, but any variable we are not differentiating with respect to is treated like it is a constant. So for f(x,y)=2x2yf(x,y)=2x^2yf(x,y)=2x2y we would treat the 2y2y2y as just a constant number and only differentiate the x2x^2x2.
