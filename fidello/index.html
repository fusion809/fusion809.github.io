using DifferentialEquations, LaTeXStrings
using Plots

# ------------------------------------------------------------
# Parameters
# ------------------------------------------------------------

g   = 9.81
l₁  = 1.0
l₂  = 1.0

m₁ᵣ = 1.0
m₁ᵦ = 1.0
m₂ᵣ = 1.0
m₂ᵦ = 1.0
fps = 30

# ------------------------------------------------------------
# Equations of motion
#
# u = [θ₁, θ₂, θ̇₁, θ̇₂]
# ------------------------------------------------------------

function double_pendulum!(du, u, p, t)

    θ₁, θ₂, θ̇₁, θ̇₂ = u

    Δ = θ₁ - θ₂

    # Common terms
    M₁ = m₁ᵣ/12 + m₁ᵦ + m₂ᵦ

    D₂ = (m₂ᵣ/12 + m₂ᵦ) * l₂ -
         (m₂ᵦ^2 * l₂^2 * cos(Δ)^2) / M₁

    F₁ = m₂ᵦ * l₂ * θ̇₂^2 * sin(Δ) +
         g * cos(θ₁) *
         (m₁ᵣ/2 + m₂ᵣ + m₁ᵦ + m₂ᵦ)

    F₂ = m₂ᵦ * (
             l₁ * θ̇₁^2 * sin(Δ) -
             g * cos(θ₂)
         )

    # Equations from the supplied expressions
    du[1] = θ̇₁
    du[2] = θ̇₂

    du[3] = -F₁ / (M₁ * l₁)

    du[4] = (
        (m₂ᵦ * cos(Δ) / M₁) * F₁ +
        F₂
    ) / D₂
end

# ------------------------------------------------------------
# Initial conditions
# ------------------------------------------------------------

θ₁₀  = 0.0
θ₂₀  = 0.0
θ̇₁₀ = 0.0
θ̇₂₀ = 0.0

u₀ = [θ₁₀, θ₂₀, θ̇₁₀, θ̇₂₀]

# ------------------------------------------------------------
# Solve
# ------------------------------------------------------------

tspan = (0.0, 60.0)

prob = ODEProblem(double_pendulum!, u₀, tspan)

sol = solve(
    prob,
    Tsit5(),
    saveat=1/fps,
    abstol=1e-9,
    reltol=1e-9
)

# ------------------------------------------------------------
# Coordinates of the two bobs
#
# The angles in the supplied equations are measured from the
# horizontal, hence:
#
# x₁ = l₁ cos(θ₁)
# y₁ = l₁ sin(θ₁)
#
# x₂ = x₁ + l₂ cos(θ₂)
# y₂ = y₁ + l₂ sin(θ₂)
# ------------------------------------------------------------

x₁ = l₁ .* cos.(sol[1, :])
y₁ = l₁ .* sin.(sol[1, :])

x₂ = x₁ .+ l₂ .* cos.(sol[2, :])
y₂ = y₁ .+ l₂ .* sin.(sol[2, :])

# ------------------------------------------------------------
# Animation
# ------------------------------------------------------------

xmin = minimum(x₂) - 0.2
xmax = maximum(x₂) + 0.2
ymin = minimum(y₂) - 0.2
ymax = maximum(y₂) + 0.2

anim = @animate for i in eachindex(sol.t)

    plot(
        [0, x₁[i], x₂[i]],
        [0, y₁[i], y₂[i]],
        linewidth=3,
        label=false,
        xlims=(xmin, xmax),
        ylims=(ymin, ymax),
        aspect_ratio=:equal,
        xlabel=L"x\ (\mathrm{metres})",
        ylabel=L"y\ (\mathrm{metres})",
        title="Double pendulum"
    )

    scatter!(
        [x₁[i], x₂[i]],
        [y₁[i], y₂[i]],
        markersize=8,
        label=false
    )
end

Prerequisite mathematics

There are several pieces of prerequisite mathematics I need to cover in order for this article to make sense for you.

Maclaurin and Taylor series

If we have a function \(f(x)\), it is usually possible to write an infinite sum (or series) that equals \(f(x)\) using \(f(x)\)'s derivatives. Namely:

\[\begin{align} f(x) &= \sum_{n=0}^{\infty} \dfrac{d^n f}{dx^n}\Big|_{x=a} \dfrac{(x-a)^n}{n!} \tag{1} \\ &= f(a) + \sum_{n=1}^{\infty}\dfrac{d^n f}{dx^n}\Big|_{x=a} \dfrac{(x-a)^n}{n!} . \tag{2} \end{align}\]

Where we are using \(\dfrac{d^n f}{dx^n}\Big|_{x=a}\) to denote the \(n\)th derivative of \(f(x)\) evaluated at \(x=a\) and \(n!\) denotes the factorial of \(n\). If you are unfamiliar, well \(n!=n\times (n-1) \times (n-2) \times(n-3) \times ... \times 1\). For instance, \(5!=5\times 4 \times 3 \times 2 \times 1=120\). As for \(0!\) it is equal to 1. As for \(a\) it is an arbitrary number we get to choose. Equation (1) is known as the Taylor series of \(f(x)\). If we truncate our Taylor series at some \(n\) value, we will get an \(n\)th-order approximation for our function that is called a Taylor polynomial. For instance, if the maximum \(n\) value we substitute in is \(5\), we will get a fifth-order approximation to our function. Keep in mind that our \(n\)th-order approximation includes the \(n\)th derivative of our function evaluated at \(x=a\).

If \(a=0\), then we get the Maclaurin series:

\[\begin{align} f(x) &= \sum_{n=0}^{\infty} \dfrac{d^n f}{dx^n}\Big|_{x=0} \dfrac{x^n}{n!} \tag{3} \\ &= f(0) + \sum_{n=1}^{\infty} \dfrac{d^n f}{dx^n}\Big|_{x=0} \dfrac{x^n}{n!}. \tag{4} \end{align}\]

Why do these equations hold? Well, try taking the \(n\)th derivative of Equations (1) and (3) and substituting \(x=a\) and \(x=0\), respectively. You will find that you get \(\dfrac{d^n f}{dx^n}\Big|_{x=a}\) and \(\dfrac{d^n f}{dx^n}\Big|_{x=0}\), respectively. Consequently, our series matches our original function in its \(n\)th derivative for \(n\in \mathbb{Z}^{+}\). Likewise, if you substitute in \(x=a\) and \(x=0\) into the Taylor and Maclaurin series, respectively, you should get \(f(a)\) and \(f(0)\), respectively. So we see that this is like a polynomial of infinite order that matches our original function for its value and derivatives value at one point. It turns out that this means it contains enough information to match our original function at other points, too.

There are exceptions where Taylor series do not accurately compute the function they pertain to. For instance, points where the function is undefined can mess things up. As an example, \(\ln{(x+1)}\)'s Maclaurin series will only approximate \(f(x)\) well for \(-1 < x \leq 1\) as at \(x=-1\) the function is undefined. Beyond these points, it will fail to converge (meaning it will not equal some finite number as terms for higher \(n\) will not get rapidly smaller as \(n\) gets bigger).

Now, I know this probably seems pretty abstract to you right now. But let us try to figure out the Maclaurin series for some example functions for which the \(n\)th derivative is fairly easy to calculate. Say, for instance, we calculate the Maclaurin series for \(e^x\). Why \(e^x\)? Because the \(n\)th derivative of \(e^x\) is just \(e^x\), and evaluating this at \(x=0\) yields 1. Hence:

\[\begin{align} e^x &= \sum_{n=0}^{\infty} \dfrac{x^n}{n!} \tag{5} \end{align}\]
is the Maclaurin series of \(e^x\). Returning to our previous discussion on order approximations, the first-order approximation to \(e^x\) based on this Maclaurin series would be the Maclaurin series terms up until \(n=1\). Which for \(e^x\) would be \(1+x\). Likewise, a second-order approximation of \(e^x\) would be \(1+x+\dfrac{x^2}{2}\). The higher order the approximation, the closer it is likely to be to the true value of our function.

Okay, let us try our hand at another function's Maclaurin series. How about \(\cos{x}\)? We know the first derivative of \(\cos{x}\) is \(-\sin{x}\). Hence the second derivative is \(-\cos{x}\). The third derivative would be \(\sin{x}\). Fourth derivative would be \(\cos{x}\). Fifth derivative would be \(-\sin{x}\) and sixth derivative would be \(-\cos{x}\). Well, I have noticed a pattern here! Seems to me like \((-1)^{\lfloor\frac{n+1}{2}\rfloor}\) (where \(\lfloor ... \rfloor\) rounds down decimals, e.g. it would take 3.6 and return 3) will recreate the sign of this function. If \(n\) is even, the trigonometric function will be \(\cos{x}\) and if it is odd it will be \(\sin{x}\). Evaluating these functions at \(x=0\), we see that if \(n\) is even we will get \(1\) from the trigonometric function and 0 if \(n\) is odd. Hence:

\[\begin{alignedat}{2} \dfrac{d^nf}{dx^n}\Big|_{x=0} &= \begin{cases} (-1)^{\lfloor\frac{n+1}{2}\rfloor} & n\hspace{0.1cm}\mathrm{even} \\ 0 & n \hspace{0.1cm}\mathrm{odd}. \end{cases} \end{alignedat}\]
So our sum will essentially just be over even numbers. One way we can denote a sum over even numbers is by replacing \(n\) with \(2n\) and summing over all numbers. As \(2\) times any integer is always an even number. In this event, our \((-1)^{\lfloor\frac{n+1}{2}\rfloor}\) becomes:

\[\begin{align} (-1)^{\lfloor\frac{2n+1}{2}\rfloor} &=(-1)^{\lfloor\frac{2n+1}{2}\rfloor} \notag \\ &= (-1)^{\lfloor n+\frac{1}{2}\rfloor} \notag \\ &= (-1)^{n}. \tag{6} \end{align}\]
We arrived at Equation (6) simply because \(n\) is an integer so adding a half to it should make no difference when we are rounding down. Consequently, our Maclaurin series becomes:

\[\begin{aligned} \cos{x} &= \sum_{n=0}^{\infty} \dfrac{(-1)^n x^{2n}}{(2n)!} \end{aligned}\]

As our powers of \(x\) are all even in this series, a first-order approximation of \(\cos{x}\) based on this Maclaurin series would be just \(1\) (as the next term in the series would be \(-\dfrac{x^2}{2}\) which is second order and hence not included).

So here is some homework for you: try constructing the Maclaurin series for \(\sin{x}\). You should arrive at:

\[\begin{aligned} \sin{x} &= \sum_{n=0}^{\infty} \dfrac{(-1)^nx^{2n+1}}{(2n+1)!}. \end{aligned}\]

As another example, we will find the Maclaurin series for \(\ln{(x+1)}\) so we can see why it only converges well for \(|x| < -1\) where \(|x|\) is the absolute value of \(x\). The first derivative is \(\dfrac{1}{x+1}\). Second derivative is \(-\dfrac{1}{(x+1)^2}\). Third derivative is \(\dfrac{2}{(x+1)^3}\). Fourth derivative is \(-\dfrac{6}{(x+1)^4}\). So it seems to me that the pattern is that the numerator is \((-1)^{n-1} (n-1)!\) and the denominator is \((x+1)^n\). Hence:

\[\begin{align} \dfrac{d^n}{dx^n} \ln{(x+1)} &= \dfrac{(-1)^{n-1}(n-1)!}{(x+1)^n}, \hspace{0.1cm} n \geq 1. \tag{7} \end{align}\]
And:
\[\begin{align} \dfrac{d^n}{dx^n} \ln{(x+1)} \Big|_{x=0} &= (-1)^{n-1}(n-1)!, \hspace{0.1cm} n \geq 1. \tag{8} \end{align}\]
Hence our Maclaurin series is:
\[\begin{align} \ln{(x+1)} &= \ln{1} + \sum_{n=1}^{\infty} \dfrac{(-1)^{n-1}(n-1)! x^n}{n!} \tag{9} \\ &= \sum_{n=1}^{\infty} \dfrac{(-1)^{n-1}x^n}{n}. \tag{10} \end{align}\]
If \(|x|>1\), we would expect the power of \(x\) in our numerator to potentially grow faster than \(n\) and hence our terms could become progressively larger as \(n\rightarrow \infty\). As for if \(x=\pm 1\), well our numerator would be smaller than our denominator, but our denominator would grow rather slowly, which means we would have to calculate a lot of terms to figure out what value it ends up equalling, assuming it does converge. If \(x=1\), we get:
\[\begin{align} \ln{2} &= \sum_{n=1}^{\infty} \dfrac{(-1)^{n-1}}{n}. \tag{11} \end{align}\]
Which is actually true. As this sum does, indeed, equal \(\ln{2}\). But because the denominator grows very slowly, we would need a lot of terms in the series in order to get a good approximation for what it equals. If \(x=-1\), then we get:
\[\begin{align} \ln{0} &= \sum_{n=1}^{\infty} \dfrac{(-1)^{n-1} (-1)^{n}}{n} \tag{12} \\ &= -\sum_{n=1}^{\infty} \dfrac{1}{n}. \tag{13} \end{align}\]
This sum does not converge, hence it actually equals \(\infty\). Hence why \(|x| < 1\) is a requirement for this Maclaurin series to converge, or at least converge at a reasonable pace, although it does also converge, albeit slowly, for \(x=1\).

Maclaurin and Taylor series have broad applications in physics. One application they have is in helping us connect more general and robust laws of physics to older approximations. For more on this, see the section on the classical limit of special relativity's kinetic energy.

Complex numbers

Complex numbers are numbers that involve both a real and an imaginary part. That is, they are of the form \(a+bi\) where \(a\) and \(b\) are both real numbers and \(i\) is the imaginary number. \(a\) is called the real part of the number and \(b\) is called the imaginary part of the number. Importantly, \(a\) and \(b\) can be zero, consequently all real numbers are technically complex numbers. We can display complex numbers in the complex plane (also known as the Argand plane) as vectors. Specifically, the \(y\) component of this vector is the imaginary part of our number and the \(x\) component is the real part of the number.

Figure shows the number \(2+3i\) displayed in the complex plane. The length of the vector, \(l\), can be calculated using the Pythagorean theorem as \(l=\sqrt{2^2+3^2}=\sqrt{13}\). \(l\) can also be called the modulus of our complex number. As for \(\theta\), the angle from the positive \(x\)-axis measure counterclockwise it can be found using the definition of the tangent function as \(\theta =\tan^{-1}{\dfrac{3}{2}}\). Note also that \(3=l\sin{\theta}\) and \(2=l\cos{\theta}\) by the definition of these trigonometric functions.

Interestingly, these two qualities, the length of the complex number's vector and its angle, measured counterclockwise from the positive \(x\)-axis, can be used to uniquely define it. To see how, I must first share with you an interesting quality of the exponential function. Namely, that:

\[\begin{aligned} e^{iz} &= \cos{z} + i\sin{z}. \end{aligned}\]
Why is this the case? Replacing \(x\) with \(iz\) in Equation (5) yields:
\[\begin{aligned} e^{iz} &= \sum_{n=0}^{\infty} \dfrac{(iz)^n}{n!}. \end{aligned}\]
You may be thinking, so what? Well, powers of \(i\) have interesting properties. Namely, \(i^0=1\), \(i^1=i\), \(i^2=-1\), \(i^3=-i\) and \(i^4=1\). Generally, \(i^{4n}\) (where \(n\) is an integer) is equal to \(1\), \(i^{4n+1}\) is \(i\), \(i^{4n+2}\) is \(-1\) and \(i^{4n+3}\) is \(-i\). Focusing on even powers, we find that \(i^{2n}=(-1)^n\) (where makes sense as \(i^2=-1\) and \(i^{2n}=(i^2)^n\)). Whereas odd powers yields \(i^{2n+1}=(-1)^n i\). Consequently:
\[\begin{aligned} e^{iz} &= \sum_{n=0}^{\infty} \dfrac{(-1)^n z^{2n}}{(2n)!} + \dfrac{(-1)^n iz^{2n+1}}{(2n+1)!} \\ &= \sum_{n=0}^{\infty} \dfrac{(-1)^n z^{2n}}{(2n)!} + \sum_{n=0}^{\infty} \dfrac{(-1)^n iz^{2n+1}}{(2n+1)!} \\ &= \sum_{n=0}^{\infty} \dfrac{(-1)^n z^{2n}}{(2n)!} + i\sum_{n=0}^{\infty} \dfrac{(-1)^n z^{2n+1}}{(2n+1)!}. \end{aligned}\]
The first of these sums we can recognize as \(\cos{z}\) whereas the second is \(\sin{z}\). Hence:
\[\begin{aligned} e^{iz} &= \cos{z} + i\sin{z}. \end{aligned}\]
An interesting thing to note that \(e^{iz}\) is that its modulus is one. How do I know this? Well, the modulus is defined as just the length of the complex number's vector in the complex plane, right? So for \(e^{iz}\) that would be:
\[\begin{aligned} l &= \sqrt{\cos^2{z}+\sin^2{z}} \\ &= \sqrt{1} \\ &= 1. \end{aligned}\]
Here I used the trigonometric identity:
\[\begin{align} \cos^2{z}+\sin^2{z}=1 \hspace{0.1cm} \forall z \in \mathbb{R}. \tag{14} \end{align}\]
Where \(\mathbb{R}\) is the set of real numbers. Okay, so getting back to how \(l\) and \(\theta\) can uniquely define a complex number. Well, interestingly you can write any complex number in the form \(le^{i\theta}\). Why? Well, recall that \(e^{i\theta}\) is just \(\cos{\theta}+i\sin{\theta}\). Looking at Figure we can clearly see that the \(x\) component of our vector is just \(l\cos{\theta}\), right? And we can also see that the \(y\) component is just \(l\sin{\theta}\) and if we expand our \(le^{i\theta}\) we get:
\[\begin{aligned} le^{i\theta} &= l\cos{\theta} + i\sin{\theta}. \end{aligned}\]
Hence \(le^{i\theta} = x+iy\). For instance, for the complex number \(2+3i\) we can rewrite it as:
\[\begin{aligned} 2+3i &= \sqrt{13}e^{i\tan^{-1}{\frac{3}{2}}}. \end{aligned}\]

Complex analysis

I have definitely not covered everything within the field of complex numbers. There's a field of maths known as complex analysis where we combine calculus and complex numbers. In it, we learn, among other things, how to integrate along curves (or contours) in the complex plane and that there is an extension of Taylor series to the complex plane called the Laurent series. In it, we write:

\[\begin{align} f(z) &= \sum_{n=-\infty}^{\infty} a_n (z-z_0)^n \tag{15} \end{align}\]
where:
\[\begin{align} a_n &= \dfrac{1}{2\pi i} \oint_C \dfrac{f(z)}{(z-z_0)^{n+1}} dz. \tag{16} \end{align}\]
This is a contour integral over a curve \(C\) that includes the point \(z=z_0\). \(z_0\) is analogous to the \(a\) in our Taylor series as it is arbitrary. There's a formula called Cauchy's differentiation formula that says that:
\[\begin{align} f^{(n)}(z_0) &= \dfrac{n!}{2\pi i} \oint_C \dfrac{f(z)}{(z-z_0)^{n+1}} dz, \hspace{0.1cm}n \in \{0, 1, 2, ...\}. \tag{17} \end{align}\]
Where \(f^{(n)}(z_0)\) is the \(n\)th derivative of \(f(z)\) evaluated at \(z=z_0\). Which helps us see how the Laurent series is connected to the Taylor series as for non-negative \(n\), \(a_n = \dfrac{f^{(n)}(z_0)}{n!}\). As for negative \(n\), \(a_n=0\) if \(f(z)\) is defined everywhere in the complex plane. Why do I mention this? Well, I personally consider complex analysis one of the most beautiful fields of mathematics and I thought I would mention it in case you are ever in a position to take a complex analysis class while at university.

Partial derivatives

Partial derivatives are just a straightforward extension of derivatives as you understand them already. The key difference is that they are derivatives of multivariable functions instead of single-variable functions. Further, when you differentiate with respect to one variable, all other variables are kept constant. If you would like to build a graphical image of what the partial derivative is, well recall that the derivative of a single-variable function is just the gradient of that function. Consequently, it is also the gradient of the tangent line to that function. The partial derivative is similar to that. As when we have a function with more than a single independent variable, we have the freedom to choose which variable or variables we wish to determine our function's gradient with respect to.

If you want to visualize this, imagine a surface defined by \(z=f(x,y)\) for example. Because a tangent line is two dimensional and we're in three dimensional space, there can be more than one tangent line to a given point. As when constructing the tangent line, we must answer a question: in which direction do we want our line to be tangential to our surface? It could be tangential in the \(x\) direction or the \(y\) direction, or even in any arbitrary direction in the \(xy\) plane. If we want the tangent line in the \(x\) direction, we will need the partial derivative with respect to \(x\) to get its gradient, whereas if we want the tangent line in the \(y\) direction, we will need the partial derivative with respect to \(y\) to get its gradient. More generally, for an arbitrary direction in the \(xy\) plane we would use the directional derivative as it is called.

Say \(f\) is a function of two variables — \(x\) and \(y\). Then its partial derivative with respect to \(x\) is formally defined as:

\[\begin{aligned} \dfrac{\partial f}{\partial x} &\stackrel{\text{def}}{=} \lim_{h\rightarrow 0} \dfrac{f(x+h, y)-f(x, y)}{h}. \end{aligned}\]

This is analogous to the first principles definition of the derivative you would have learned for standard derivatives. Namely, if we are differentiating \(f(x)\):

\[\begin{aligned} \dfrac{df}{dx} &= \lim_{h\rightarrow 0}\dfrac{f(x+h) - f(x)}{h}. \end{aligned}\]
The only difference is that now we also have a variable \(y\) that our function \(f(x,y)\) depends on, but is kept constant when differentiating with respect to \(x\). Say \(f(x,y)=2x^2y\). Then \(\dfrac{\partial f}{\partial x}\) would be:
\[\begin{aligned} \dfrac{\partial f}{\partial x} &= \lim_{h\rightarrow 0} \dfrac{2(x+h)^2y - 2x^2y}{h}. \end{aligned}\]
Did you notice that \(2y\) is a common factor of both terms in our numerator? Let us take it out of our limit altogether, as it is effectively a constant (it does not depend on \(h\), after all).

\[\begin{aligned} \dfrac{\partial f}{\partial x} &= 2y\lim_{h\rightarrow 0} \dfrac{(x+h)^2-x^2}{h} \end{aligned}\]
Using the binomial theorem, we know that
\[\begin{aligned} (x+h)^2 &= x^2 + 2xh + h^2. \end{aligned}\]

Hence:

\[\begin{aligned} \dfrac{\partial f}{\partial x} &= 2y\lim_{h\rightarrow 0} \dfrac{x^2+2xh + h^2-x^2}{h} \\ &= 2y\lim_{h\rightarrow 0} \dfrac{2xh + h^2}{h} \\ &= 2y\lim_{h\rightarrow 0} 2x + h \\ &= 2y \cdot 2x \\ &= 4xy. \end{aligned}\]
Okay, so that is the long way of finding out partial derivatives. Fortunately, there is also a faster way. Which is that we apply normal differentiation rules, but any variable we are not differentiating with respect to is treated like it is a constant. So for \(f(x,y)=2x^2y\) we would treat the \(2y\) as just a constant number and only differentiate the \(x^2\). Applying the power rule, we see that \(\dfrac{d}{dx}x^2 = 2x\) and hence:
\[\begin{aligned} \dfrac{\partial f}{\partial x} &= 2y \cdot 2x \\ &= 4xy. \end{aligned}\]

Heat equation

One of the simplest partial differential equations is the heat equation. In its simplest form it is:

\[\begin{align} \dfrac{\partial u}{\partial t} &= \alpha \dfrac{\partial^2 u}{\partial x^2} \tag{18} \end{align}\]
Where \(u(x,t)\) is a function describing the temperature of the one-dimensional object (only one dimensional as the above heat equation only has a single spatial dimension, if we want more spatial dimensions we'll have to add second partial derivatives with respect to those other dimensions, too) we're modelling and \(\alpha\) is some constant. I know this equation may look confusing at first glance, but it is actually saying something rather intuitive to you.

Do you remember from your maths class that the second derivative of a function is its concavity? So if the second derivative is negative, that means our function is concave down — it is leading to some sort of maximum. Whereas if it is positive, the function is concave up, which means it is going up from some minimum. We have the second derivative with respect to space on the right-hand side of Equation (18), so it essentially returns positive if we have a localized colder area and neighbouring hotter points. Whereas it returns negative if we have a really hot point surrounded by cooler points. The left-hand side of Equation (18), however, represents the rate of change of our function in time.

Equation (18) therefore essentially says that if we are in a region where there is a really cold point surrounded by hotter points, the temperature will increase in the short-term for that colder point. Whereas the equation says that the temperature will decrease in a hotter region surrounded by colder points. If you have ever brought something hot out of the oven, or put something of room temperature into the fridge or freezer, this should make intuitive sense to you.

Product notation

When we wish to denote a multi-term product, we can use the product notation \(\displaystyle \prod_{i=1}^n a_i\). This essentially says that we multiply \(a_1\), \(a_2\), \(a_3\) and so on until \(a_n\). It is similar to the summation notation \(\sum_{i=1}^n a_i\), with the difference being that instead of addition signs being between each term we have multiplication signs instead.

For instance, for the product \(\displaystyle \prod_{i=1}^n 2i-1\) we would multiply \(2i-1\) for \(i=1\), \(i=2\), \(i=3\), and so forth up until \(i=n\). If we set \(n=3\), then:

\[\begin{aligned} \displaystyle \prod_{i=1}^3 2i-1 &= (2(1)-1) \times (2(2)-1) \times (2(3)-1) \\ &= 1 \times 3 \times 5 \\ &= 15. \end{aligned}\]

Lagrangian mechanics

Lagrangian mechanics is one of three major formulations of classical mechanics with the others being Newtonian mechanics and Hamiltonian mechanics. Classical mechanics as a whole is a branch of physics most applicable to the situations that humans most often encounter, as it does not account for quantum randomness (hence cannot be applied to very small scales), nor does it account for relativistic effects (which are most relevant when dealing with strong gravitational fields or velocities close to the speed of light). In Lagrangian mechanics, we define a quantity known as the Lagrangian of our physical system:

\[\begin{align} L &\stackrel{\text{def}}{=} T - V. \tag{19} \end{align}\]
Where \(T\) is kinetic energy and \(V\) is potential energy of our entire physical system. It is important to note that only conservative forces contribute to \(V\). Lagrangian mechanics can account for non-conservative (i.e. dissipative) forces, too, but we will get to how one handles them later.

The distinction between conservative and non-conservative forces is whether they change the net energy of your system. For instance, gravity does not because any increase in kinetic energy it causes is balanced by a corresponding reduction in potential energy. Likewise, any loss of kinetic energy caused by gravity is balanced by an increase in potential energy. Consequently, it is a conservative force. Air resistance, however, is a non-conservative force because the losses it causes in kinetic energy are not balanced by increases in potential energy.

Euler-Lagrange equations

When there are no non-conservative forces, the equations of motion can be derived by first determining our system's Lagrangian and then applying a set of partial differential equations known as the Euler-Lagrange equations to this Lagrangian. The Euler-Lagrange equations are:

\[\begin{align} \hspace{4cm}\dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i} - \dfrac{\partial L}{\partial q_i} &= 0, \hspace{2cm} i\in \{1,2,3,...,n\}. \tag{20} \end{align}\]
\(q_i\) are the \(n\) degrees of freedom (or generalized coordinates) of our problem and \(\dot{q}_i\) are their time derivatives (or the generalized velocities). The \(\dfrac{d}{dt}\) is not a partial derivative and this is purposeful, as when we differentiate \(\dfrac{\partial L}{\partial \dot{q}_i}\) with respect to \(t\), we treat \(q_i\) and \(\dot{q}_i\) as functions of \(t\) and wherever they appear in \(\dfrac{\partial L}{\partial \dot{q}_i}\) we differentiate them against \(t\).

Next, I should explain what "degrees of freedom" are. They are essentially our variables of interest. For simpler problems, the degrees of freedom in our problem are often the spatial dimensions of our problem. For instance, if we were to study an object in free fall and we were to try to simplify our problem as much as possible and not consider any movement in the horizontal directions then \(n\) could be 1 and \(q_1\) would just be the height of the object above ground level.

Likewise, when we study the simple pendulum — which is a problem in which we have an idealized rigid pendulum whose rod has zero mass, zero friction and for which there is absolutely no air resistance — typically we only consider a single degree of freedom, which is the angle our pendulum's rod makes with either the negative \(y\) axis or the positive \(x\) axis, depending on the preferences of whoever is setting up the problem.

Derivation of Equations (20)

The derivation of Equations (20) requires knowledge of a field of mathematics known as the calculus of variations as well as a physics principle known as the stationary action principle. I will provide my own derivation here; although, I would suggest checking out Veritasium's video on this topic as it provides a more accessible introduction to this topic.

There is a quantity known as the action — which is denoted as \(S\) — that is defined as:

\[\begin{align} S &\stackrel{\text{def}}{=} \int_{t_0}^{t_f} L(q_i, \dot{q}_i, t) dt. \tag{21} \end{align}\]

One interesting property of the action is that nature consistently sets it to its stationary point, and this is regardless of context. Regardless of whether we are examining the motion of planets with Newton's second law, or studying the behaviour of black holes with general relativity, or checking out the behaviour of subatomic particles, there is always an action that is at its stationary point. If you would like an explanation for how this arises in classical mechanics, I suggest checking out this excellent video by Dr Jorge S Diaz. Traditionally, this stationary point is typically thought of as a minimum (hence why this is also known as the principle of least action), but strictly speaking it is not always a minimum.

Of all the paths that an object could explore, the one that it actually explores is the one that sets the action to its stationary point. Figure provides some example paths that we examine when applying the principle of stationary action. In the terminology of the calculus of variations, we can express the fact the action is at its stationary point as:

\[\begin{align} \delta S &= 0. \tag{22} \end{align}\]
This is analogous to saying, in regular calculus, that our function's first derivative is zero. Which, as you may remember from your maths classes, is an equation we can solve to find the stationary point(s) of our function. The difference is that \(S\) is not a function that takes some value of an independent variable (e.g. \(x\)) and returns a value, instead \(S\) is a functional. Which means that it takes a function as its input and returns a value. In this case, the function it takes as its input are the \(q_i(t)\) that specify our path. This is what distinguishes calculus of variations from regular calculus. In calculus of variations, we are working with functionals, whereas in regular calculus we are working with functions.

Say we add functions \(\delta q_i\) to \(q_i\), thereby adjusting the path our object takes. Crucially, however, the end times and end points of our path will be unchanged. The new, adjusted action we will denote by \(S'\) and it is:

\[\begin{aligned} S' &= \int_{t_0}^{t_f} L(q_i+\delta q_i, \dot{q}_i+\delta \dot{q}_i, t) dt \end{aligned}\]
We will expand \(L\) using the first couple of terms of its Taylor series around \(a=q_i\) and \(a=\dot{q}_i\) (we have multiple \(a\)s as our function depends on multiple variables):
\[\begin{aligned} S' &\approx \int_{t_0}^{t_f} L(q_i, \dot{q}_i, t) + \sum_{i=1}^n\dfrac{\partial L}{\partial q_i} \delta q_i + \dfrac{\partial L}{\partial \dot{q}_i}\delta \dot{q}_i dt. \end{aligned}\]
Next, we will apply integration by parts to the \(\dfrac{\partial L}{\partial \dot{q}_i}\delta \dot{q}_i\) term:
\[\begin{aligned} S' &\approx \int_{t_0}^{t_f} L(q_i, \dot{q}_i, t) + \sum_{i=1}^n\dfrac{\partial L}{\partial q_i} \delta q_i dt + \left[\sum_{i=1}^n\dfrac{\partial L}{\partial \dot{q}_i}\delta q_i\right]_{t_0}^{t_f} - \int_{t_0}^{t_f} \sum_{i=1}^n\dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i}\delta q_i dt. \end{aligned}\]
At the end times of our path, \(\delta q_i\) should be zero, as the endpoints are fixed. Hence the term \(\left[\dfrac{\partial L}{\partial \dot{q}_i}\delta q_i\right]_{t_0}^{t_f}\) should evaluate to zero. Our expression then simplifies to:
\[\begin{aligned} S' &\approx \int_{t_0}^{t_f} L(q_i, \dot{q}_i, t) + \sum_{i=1}^n\dfrac{\partial L}{\partial q_i} \delta q_i dt - \int_{t_0}^{t_f} \sum_{i=1}^n\dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i}\delta q_i dt \\ &\approx \int_{t_0}^{t_f} L(q_i, \dot{q}_i, t) + \sum_{i=1}^n\delta q_i \left(\dfrac{\partial L}{\partial q_i} - \dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i}\right) dt. \end{aligned}\]
The first of these terms is present in \(S\), too. Hence:
\[\begin{aligned} S' - S &\approx \int_{t_0}^{t_f}\sum_{i=1}^n\delta q_i \left(\dfrac{\partial L}{\partial q_i} - \dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i}\right) dt. \end{aligned}\]
We can denote this first-order approximation to how much \(S\) changes as \(\delta S\). It is a first-order approximation as this is the highest power of \(\delta q_i\) and \(\delta \dot{q}_i\) it depends on. First order also describes the highest order derivatives of \(L\) with respect to \(q_i\) and \(\dot{q}_i\) that our approximation depends upon. Hence:
\[\begin{align} \delta S &= \int_{t_0}^{t_f} \sum_{i=1}^n\delta q_i \left(\dfrac{\partial L}{\partial q_i} - \dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i}\right) dt. \tag{23} \end{align}\]
Hence \(\delta S\) will equal zero irrespective of \(\delta q_i\) if and only if Equations (20) hold. Hence from setting \(\delta S=0\) we get the Euler-Lagrange equations.

Terminology

In Equation (20):

\[\begin{align} p_i \stackrel{\text{def}}{=} \dfrac{\partial L}{\partial \dot{q}_i} \tag{24} \end{align}\]
is known as the canonical (or generalized) momentum. It becomes especially relevant later when we cover Hamiltonian mechanics.

Non-conservative forces

I guess next I should explain how we account for non-conservative forces. Essentially we replace the \(0\) in Equations (20) with the generalized force \(Q_i\). It is defined as:

\[\begin{align} Q_i &\stackrel{\text{def}}{=} \sum_{j=1}^m \textbf{F}_j \cdot \dfrac{\partial \textbf{r}_j}{\partial q_i}. \tag{25} \end{align}\]
Where \(\textbf{F}_j\) represents the vector of the \(j\)th non-conservative force we wish to account for in our equations of motion. As you can see by the summation bounds, we have \(m\) non-conservative forces we wish to account for. \(\textbf{r}_j\) is the position vector for force \(j\). \(\textbf{F}_j\cdot\dfrac{\partial \textbf{r}_j}{\partial q_i}\) denotes the dot product between \(\textbf{F}_j\) and \(\dfrac{\partial \textbf{r}_j}{\partial q_i}\) (which can be called the covariant basis vector). Alternatively, to calculate \(Q_i\) we can use velocities instead of positions:
\[\begin{align} Q_i &\stackrel{\text{def}}{=} \sum_{j=1}^m \textbf{F}_j \cdot \dfrac{\partial \dot{\textbf{r}}_j}{\partial \dot{q}_i}. \tag{26} \end{align}\]
\(\dot{\textbf{r}}_j\) is the time derivative of the position vector (that is, the velocity vector) for force \(j\). Hence the more generalized form of Equations (20) is:
\[\begin{align} \hspace{4cm}\dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i} - \dfrac{\partial L}{\partial q_i} &= \sum_{j=1}^m \textbf{F}_j \cdot \dfrac{\partial \textbf{r}_j}{\partial q_i}, \hspace{2cm} i\in\{1,2,3,...,n\}. \tag{27} \end{align}\]
The velocity-based definition of the covariant basis vectors can also be used, which yields:
\[\begin{align} \hspace{4cm}\dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{q}_i} - \dfrac{\partial L}{\partial q_i} &= \sum_{j=1}^m \textbf{F}_j \cdot \dfrac{\partial \dot{\textbf{r}}_j}{\partial \dot{q}_i}, \hspace{2cm} i\in\{1,2,3,...,n\}. \tag{28} \end{align}\]

Examples

Single pendulum

So to punctuate how one applies Equations (20) and (27), I thought I would give you a nice, simple example: the single pendulum.

Without air resistance

To apply Equations (20), we will treat it as a simple pendulum with no friction, a massless rod and no air resistance. The pendulum will consist of a rod with a bob at one end and freely rotating around a central point. We will define this central point as being the origin in Cartesian coordinates. Say the rod is of fixed length \(l\) metres. The pendulum bob will be of mass \(m\) kilograms. As you can see in Figure , we have defined \(\theta\) as the angle between the rod and the positive \(x\)-axis going counter-clockwise. Hence the \(x\) and \(y\) coordinates of the pendulum bobs are:

\[\begin{aligned} x &= l\cos{\theta} \\ y &= l\sin{\theta}. \end{aligned}\]
Hence:
\[\begin{aligned} \dot{x} &= -l\dot{\theta}\sin{\theta} \\ \dot{y} &= l\dot{\theta}\cos{\theta}. \end{aligned}\]
As for velocity squared, it is defined as:
\[\begin{aligned} v^2 &= \dot{x}^2+\dot{y}^2 \\ &= l^2\dot{\theta}^2\sin^2{\theta} + l^2\dot{\theta}^2\cos^2{\theta} \\ &= l^2\dot{\theta}^2. \end{aligned}\]
Hence \(v=l\dot{\theta}\). The kinetic energy is:
\[\begin{aligned} T &= \dfrac{mv^2}{2} \\ &= \dfrac{ml^2\dot{\theta}^2}{2}. \end{aligned}\]
As for potential energy, given this bob is moving solely under the force of gravity:
\[\begin{aligned} V &= mgy \\ &= mgl\sin{\theta}. \end{aligned}\]
Hence:
\[\begin{aligned} L &= T - V \\ &= \dfrac{ml^2\dot{\theta}^2}{2} - mgl\sin{\theta}. \end{aligned}\]
\(\dfrac{\partial L}{\partial \dot{\theta}}\) is hence:
\[\begin{aligned} \dfrac{\partial L}{\partial \dot{\theta}} &= ml^2 \dot{\theta}. \end{aligned}\]
And its time derivative is:
\[\begin{aligned} \dfrac{d}{dt}\dfrac{\partial L}{\partial \dot{\theta}} = ml^2 \ddot{\theta}. \end{aligned}\]
As for the \(\dfrac{\partial L}{\partial \theta}\) term it is:
\[\begin{aligned} \dfrac{\partial L}{\partial \theta} &= -mgl\cos{\theta}. \end{aligned}\]
So Equations (20) becomes:
\[\begin{aligned} ml^2 \ddot{\theta} + mgl\cos{\theta} &= 0. \end{aligned}\]
Dividing by \(ml^2\) and taking the second term to the right-hand side yields:
\[\begin{align} \ddot{\theta} &= -\dfrac{g}{l}\cos{\theta}. \tag{29} \end{align}\]
Equation (29) has, as its highest order derivative, a second-order derivative. It also only involves ordinary derivatives (not partial derivatives). Hence it is a second-order ordinary differential equation (ODE). Second-order ODEs are typically obtained in both Newtonian and Lagrangian mechanics. The number of second-order ODEs obtained for a given system depends on the number of degrees of freedom of the system.

Technically speaking it is possible to analytically solve Equation (29), but it requires the use of non-standard functions called elliptic integrals. Another option is we can use the Taylor series around \(a=-\dfrac{\pi}{2}\). Why \(-\dfrac{\pi}{2}\)? Because this corresponds to the pendulum being on the negative \(y\) axis. This is an equilibrium point of the simple pendulum, as if the pendulum has no kinetic energy (in other words \(\dot{\theta}=0\)) when it is at this point, it will stay perfectly still and remain at \(\theta=-\dfrac{\pi}{2}\) forever. So what we want to study with the Taylor series is what happens if we only slightly perturb the pendulum from this equilibrium point, as a slight perturbation from this point should keep \(\cos{\theta}\) well approximated by the first couple of terms of its Taylor series. Okay, so we already know the \(n\)th derivative of \(\cos{\theta}\) with respect to \(\theta\) from the Maclaurin and Taylor series section, it is:

\[\begin{aligned} \dfrac{d^n}{d\theta^n} \cos{\theta} &= \begin{cases} (-1)^{\lfloor \dfrac{n+1}{2}\rfloor} \cos{\theta}, \hspace{0.2cm}n\hspace{0.1cm}\mathrm{even}\\ (-1)^{\lfloor \dfrac{n+1}{2}\rfloor} \sin{\theta}, \hspace{0.2cm}n\hspace{0.1cm}\mathrm{odd} \end{cases}. \end{aligned}\]
If we replace even \(n\) values with \(2n\) (where \(n\) here is simply a non-negative integer) and odd \(n\) with \(2n+1\):
\[\begin{aligned} \dfrac{d^{2n}}{d\theta^{2n}} \cos{\theta} &= (-1)^{n} \cos{\theta} \\ \dfrac{d^{2n+1}}{d\theta^{2n+1}} \cos{\theta} &= (-1)^{n+1} \sin{\theta}. \end{aligned}\]
Substituting in \(\theta=a\) which is \(-\dfrac{\pi}{2}\):
\[\begin{aligned} \dfrac{d^{2n}}{d\theta^{2n}} \cos{\theta} \Big|_{\theta=-\dfrac{\pi}{2}} &= (-1)^{n} \cdot 0 \\ &= 0 \\ \dfrac{d^{2n+1}}{d\theta^{2n+1}} \cos{\theta} \Big|_{\theta=-\dfrac{\pi}{2}} &= (-1)^{n+1} \cdot -1 \\ &= (-1)^{n+2} \\ &= (-1)^n. \end{aligned}\]
Hence our Taylor series is:
\[\begin{aligned} \cos{\theta} &= \sum_{n=0}^{\infty} \dfrac{(-1)^{n} \left(\theta-(-\dfrac{\pi}{2})\right)^{2n+1}}{(2n+1)!} \\ &= \sum_{n=0}^{\infty} \dfrac{(-1)^{n} \left(\theta+\dfrac{\pi}{2}\right)^{2n+1}}{(2n+1)!}. \end{aligned}\]
Now we want to make our differential equation as simple as possible, so we will only consider the first term in this Taylor series, the \(n=1\) term. In which case \(\cos{\theta} \approx \theta + \dfrac{\pi}{2}\). Hence Equation (29) becomes:
\[\begin{align} \ddot{\theta} &=-\dfrac{g}{l}\theta - \dfrac{g\pi}{2l}. \tag{30} \end{align}\]
What function if double differentiated yields the original function back with \(-\dfrac{g}{l}\) coefficient and a constant term? The answer is:
\[\begin{aligned} \theta(t) &= C_1 \cos{\left(\sqrt{\dfrac{g}{l}}t\right)} + C_2 \sin{\left(\sqrt{\dfrac{g}{l}}t\right)} + C_3. \end{aligned}\]
Where \(C_1\) and \(C_2\) are constants that depend on our initial conditions (similarly to the arbitrary constants of integration you get when using indefinite integrals) and \(C_3\) is a constant we will work out next, right after differentiating \(\theta(t)\) for later use:
\[\begin{aligned} \dot{\theta}(t) &= -\sqrt{\dfrac{g}{l}}C_1\sin{\left(\sqrt{\dfrac{g}{l}}t\right)} + \sqrt{\dfrac{g}{l}}C_2 \cos{\left(\sqrt{\dfrac{g}{l}}t\right)}. \end{aligned}\]
\(C_3\) is a constant, so double differentiating it will remove it. Hence we know that \(C_3\) only enters Equation (30) via the \(\theta\) term on the right-hand side. So we need to impose the condition that:
\[\begin{aligned} -\dfrac{g}{l}C_3 - \dfrac{g\pi}{2l} &= 0 \end{aligned}\]
to ensure that the left-hand side and right-hand sides of Equation (30) match. Multiplying \(-\dfrac{l}{g}\) yields:
\[\begin{aligned} C_3 + \dfrac{\pi}{2} &= 0 \end{aligned}\]
Subtracting \(\dfrac{\pi}{2}\) yields:
\[\begin{aligned} C_3 &= -\dfrac{\pi}{2}. \end{aligned}\]
At \(t=0\), let \(\theta = \theta_0\) and \(\dot{\theta}=\dot{\theta}_0\). These values simply represent the initial values of \(\theta\) and \(\dot{\theta}\).
\[\begin{aligned} \theta_0 &= C_1 \cos{0} + C_2 \sin{0} - \dfrac{\pi}{2} \\ &= C_1 - \dfrac{\pi}{2}. \end{aligned}\]
Adding \(\dfrac{\pi}{2}\) to both sides yields:
\[\begin{aligned} C_1 &= \theta_0 + \dfrac{\pi}{2}. \end{aligned}\]
As for \(\dot{\theta}_0\):
\[\begin{aligned} \dot{\theta}_0 &= -\sqrt{\dfrac{g}{l}}\left(\theta_0 + \dfrac{\pi}{2}\right)\sin{0} + \sqrt{\dfrac{g}{l}}C_2 \cos{0} \\ &= \sqrt{\dfrac{g}{l}}C_2 \end{aligned}\]
Multiplying both sides \(\sqrt{\dfrac{l}{g}}\):
\[\begin{aligned} C_2 &= \sqrt{\dfrac{l}{g}} \dot{\theta}_0. \end{aligned}\]
Hence:
\[\begin{aligned} \theta(t) &= \left(\theta_0 + \dfrac{\pi}{2}\right)\cos{\left(\sqrt{\dfrac{g}{l}}t\right)} + \dot{\theta}_0 \sqrt{\dfrac{l}{g}} \sin{\left(\sqrt{\dfrac{g}{l}}t\right)} -\dfrac{\pi}{2}. \end{aligned}\]
So we can see \(\theta(t)\) is approximated, when it deviates only slightly from \(\theta=-\dfrac{\pi}{2}\), quite well by sine and cosine functions. More generally, we can use numerical techniques to approximate our solution. Below is some Julia code that numerically approximates the solution for \(\theta_0=\dot{\theta}_0=0\), \(g=9.81\mathrm{m}\cdot \mathrm{s}^{-2}\), \(l=1\mathrm{m}\) and \(m=1\mathrm{kg}\). These initial conditions means the pendulum starts stationary on the positive \(x\)-axis. Then gravity pulls it down and up towards the negative \(x\)-axis (at \(\theta=-\pi\)) and then back down and towards the positive \(x\)-axis (\(\theta=0\)) and over and over. Simple pendulum simulation code.

using DifferentialEquations, Plots, LaTeXStrings
ENV["GKSwstype"] = "100"
g, l = 9.81, 1.0
fps = 30

function pendulum!(du, u, p, t)
    du[1] = u[2]
    du[2] = -(g/l)*cos(u[1])
end

tspan = (0.0, 10.0)
u0 = [0.0, 0.0]  # θ₀ = 0, θ̇₀ = 0

prob = ODEProblem(pendulum!, u0, tspan)
sol = solve(prob, saveat=1/fps)

plot(sol.t, sol[1, :], label=false)
xlabel!(L"t\;(\mathrm{seconds})")
ylabel!(L"\theta\;(\mathrm{radians})")
title!("Simple pendulum plot")
savefig("Simple_pendulum_theta.svg")
# Animate with θ measured counterclockwise from the positive x-axis
x = l .* cos.(sol[1, :])
y = l .* sin.(sol[1, :])

anim = @animate for i in eachindex(sol.t)
    plot(
        [0, x[i]], [0, y[i]];
        xlims=(-1.1l, 1.1l),
        ylims=(-1.1l, 1.1l),
        aspect_ratio=:equal,
        label=false,
        xlabel=L"x\ (\mathrm{metres})",
        ylabel=L"y\ (\mathrm{metres})",
        title="Simple pendulum",
    )
    scatter!([x[i]], [y[i]]; markersize=8, label=false)
end

With air resistance

For the sake of simplicity, we will only consider the air resistance experienced by the pendulum bob itself, not by the rod. The air resistance force vector for the pendulum bob would be:

\[\begin{aligned} \textbf{F}_D &= -\dfrac{\rho C_D A|v|\textbf{v}}{2}. \end{aligned}\]
Where \(\textbf{v}\) is the velocity vector of the bob. It is equal to \((\dot{x}, \dot{y})\). Hence:
\[\begin{aligned} \textbf{F}_D &= -\dfrac{\rho C_D Al|\dot{\theta}|}{2}(\dot{x}, \dot{y}) \\ &= -\dfrac{\rho C_D Al|\dot{\theta}|}{2} (-l\dot{\theta}\sin{\theta}, l\dot{\theta}\cos{\theta}) \\ &= \dfrac{\rho C_D Al^2|\dot{\theta}|\dot{\theta}}{2} (\sin{\theta}, -\cos{\theta}). \end{aligned}\]
To find the generalized force term, we need to find \(\dfrac{\partial \textbf{r}}{\partial \theta}\):
\[\begin{aligned} \dfrac{\partial \textbf{r}}{\partial \theta} &= \left(\dfrac{\partial x}{\partial \theta}, \dfrac{\partial y}{\partial \theta}\right) \\ &= (-l\sin{\theta}, l\cos{\theta}). \end{aligned}\]
Hence:
\[\begin{align} Q_{\theta} &= \textbf{F}_D \cdot \dfrac{\partial \textbf{r}}{\partial \theta} \notag \\ &= \dfrac{\rho C_D Al^2|\dot{\theta}|\dot{\theta}}{2} (\sin{\theta}, -\cos{\theta}) \cdot (-l\sin{\theta}, l\cos{\theta}) \notag \\ &= \dfrac{\rho C_D Al^2|\dot{\theta}|\dot{\theta}}{2}(-l\sin^2{\theta}-l\cos^2{\theta}) \notag \\ &= -\dfrac{\rho C_D Al^3|\dot{\theta}|\dot{\theta}}{2}. \tag{31} \end{align}\]
Hence Equations (27) become:
\[\begin{aligned} ml^2 \ddot{\theta} + mgl\cos{\theta} &= -\dfrac{\rho C_D Al^3|\dot{\theta}|\dot{\theta}}{2}. \end{aligned}\]
Dividing by \(ml^2\) yields:
\[\begin{aligned} \ddot{\theta} + \dfrac{g}{l}\cos{\theta} &= -\dfrac{\rho C_D Al|\dot{\theta}|\dot{\theta}}{2m}. \end{aligned}\]
Subtracting \(\dfrac{g}{l}\cos{\theta}\) from both sides yields:
\[\begin{aligned} \ddot{\theta} &= -\dfrac{g}{l}\cos{\theta} -\dfrac{\rho C_D Al|\dot{\theta}|\dot{\theta}}{2m}. \end{aligned}\]
This equation cannot be analytically solved, so numerical solutions are necessary. There is a numerical solver for an even more complex version of the dampened single pendulum here. Gravitational two-body problem

In this example, we are modelling the motion of a moving mass around a mass centred at the origin. The relationship between these polar coordinates and our Cartesian coordinates are, for our moving mass:
\[\begin{aligned} x &= r\cos{\theta} \\ y &= r\sin{\theta}. \end{aligned}\]
Their time derivatives are, by the product and chain rules:
\[\begin{aligned} \dot{x} &= \dot{r} \cos{\theta} - r\dot{\theta}\sin{\theta} \\ \dot{y} &= \dot{r}\sin{\theta} + r\dot{\theta}\cos{\theta}. \end{aligned}\]
Hence velocity squared is:
\[\begin{aligned} v^2 &= \dot{x}^2 + \dot{y}^2 \\ &= (\dot{r} \cos{\theta} - r\dot{\theta}\sin{\theta})^2 + (\dot{r}\sin{\theta} + r\dot{\theta}\cos{\theta})^2 \end{aligned}\]
Using the binomial theorem, we expand these two brackets to:
\[\begin{aligned} v^2 &= \dot{r}^2 \cos^2{\theta} + r^2 \dot{\theta}^2 \sin^2{\theta} - 2r\dot{r}\dot{\theta}\cos{\theta}\sin{\theta} + \dot{r}^2 \sin^2{\theta} + r^2 \dot{\theta}^2 \cos^2{\theta} + 2r\dot{r} \dot{\theta}\sin{\theta}\cos{\theta} \end{aligned}\]
The \(2r\dot{r}\dot{\theta}\sin{\theta}\cos{\theta}\) terms have opposite signs and hence cancel each other out:
\[\begin{aligned} v^2 &= \dot{r}^2 (\cos^2{\theta}+\sin^2{\theta}) + r^2 \dot{\theta}^2 (\sin^2{\theta}+\cos^2{\theta}) \\ &= \dot{r}^2 + r^2 \dot{\theta}^2. \end{aligned}\]
This gives the kinetic energy:
\[\begin{aligned} T &= \dfrac{m}{2} \left(\dot{r}^2 + r^2 \dot{\theta}^2\right). \end{aligned}\]
Where \(m\) is the mass of the moving mass. If \(M\) is the mass of the central mass and \(G\) is the gravitational constant:
\[\begin{aligned} V &= -\dfrac{GMm}{r}. \end{aligned}\]
Hence the Lagrangian is:
\[\begin{aligned} L &= T - V \\ &= \dfrac{m}{2}\left(\dot{r}^2 + r^2 \dot{\theta}^2\right) + \dfrac{GMm}{r}. \end{aligned}\]
The momentum canonical to \(\theta\) is:
\[\begin{aligned} p_{\theta} &= \dfrac{\partial L}{\partial \dot{\theta}} \\ &= mr^2 \dot{\theta}. \end{aligned}\]
As for \(\dfrac{\partial L}{\partial \theta}\) it is:
\[\begin{aligned} \dfrac{\partial L}{\partial \theta} &= 0. \end{aligned}\]
Hence the Euler-Lagrange equation for \(\theta\) is:
\[\begin{aligned} \dfrac{d}{dt}\left(mr^2\dot{\theta}\right) &= 0. \end{aligned}\]
Which implies that \(mr^2 \dot{\theta}\), which is also called the angular momentum, is constant. We will denote this by \(p_{\theta}\). Hence:
\[\begin{align} \dot{\theta} &= \dfrac{p_{\theta}}{mr^2}. \tag{32} \end{align}\]
Hence the momentum canonical to \(r\) is:
\[\begin{aligned} p_r &= \dfrac{\partial L}{\partial \dot{r}} \\ &= m\dot{r}. \end{aligned}\]
As for \(\dfrac{\partial L}{\partial r}\) is:
\[\begin{aligned} \dfrac{\partial L}{\partial r} &= mr\dot{\theta}^2 - \dfrac{GMm}{r^2}. \end{aligned}\]
Hence the Euler-Lagrange equation for \(r\) is:
\[\begin{aligned} m\ddot{r} - mr\dot{\theta}^2 + \dfrac{GMm}{r^2} &= 0. \end{aligned}\]
Dividing by \(m\) yields:
\[\begin{align} \ddot{r} - r\dot{\theta}^2 + \dfrac{GM}{r^2} &= 0. \tag{33} \end{align}\]
Substituting in Equation (32):
\[\begin{aligned} \ddot{r} - r\dfrac{p_{\theta}^2}{m^2r^4} + \dfrac{GM}{r^2} &= 0 \\ \ddot{r} - \dfrac{p_{\theta}^2}{m^2r^3} + \dfrac{GM}{r^2} &= 0. \end{aligned}\]
Let \(u=\dfrac{1}{r}\). Then \(r=\dfrac{1}{u}\) and \(\dot{r}=-\dfrac{\dot{u}}{u^2}\). We are going to focus on geometrically solving this problem, so we will convert our differential equation from being with respect to \(t\) to being with respect to \(\theta\). Hence:

\[\begin{aligned} \dot{u} &= \dfrac{du}{dt} \\ &= \dfrac{du}{d\theta} \dfrac{d\theta}{dt}. \end{aligned}\]
We will denote \(\dfrac{du}{d\theta}\) as \(u'\). Using Equation (32) we get:
\[\begin{aligned} \dot{u} &= u' \dfrac{p_{\theta}}{mr^2} \\ &= \dfrac{p_{\theta} u'u^2}{m}. \end{aligned}\]
Hence:
\[\begin{aligned} \dot{r} &= -\dfrac{p_{\theta} u'u^2}{mu^2} \\ &= -\dfrac{p_{\theta}u'}{m}. \end{aligned}\]
Differentiating with respect to \(t\) again yields:
\[\begin{aligned} \ddot{r} &= -\dfrac{p_{\theta}\dot{u'}}{m}. \end{aligned}\]
Hence:
\[\begin{aligned} \dot{u'} &= \dfrac{d(u')}{dt} \\ &= \dfrac{d(u')}{d\theta} \dfrac{d\theta}{dt} \\ &= u'' \dfrac{p_{\theta}}{mr^2} \\ &= \dfrac{p_{\theta} u'' u^2}{m}. \end{aligned}\]
Hence:
\[\begin{aligned} \ddot{r} &= -\dfrac{p_{\theta}^2 u''u^2}{m^2}. \end{aligned}\]
Substituting this into Equation (33) yields:
\[\begin{aligned} -\dfrac{p_{\theta}^2 u''u^2}{m^2} - \dfrac{p_{\theta}^2 u^3}{m^2} + GMu^2 &= 0 \end{aligned}\]
. Dividing both sides by \(u^2\) yields:
\[\begin{aligned} -\dfrac{p_{\theta}^2 u''}{m^2} - \dfrac{p_{\theta}^2 u}{m^2} + GM &= 0 \end{aligned}\]
Multiplying by \(-\dfrac{m^2}{p_{\theta}^2}\) yields:
\[\begin{aligned} u'' + u - \dfrac{GMm^2}{p_{\theta}^2} &= 0. \end{aligned}\]
The solution to this ordinary differential equation is:
\[\begin{aligned} u(\theta) &= C_1 \cos{\theta} + C_2 \sin{\theta} + \dfrac{GMm^2}{p_{\theta}^2}. \end{aligned}\]
Let \(\mu=\dfrac{GMm^2}{p_{\theta}^2}\). Say that we can rewrite our constants \(C_1\) and \(C_2\) as:
\[\begin{aligned} C_1 &= e\mu \cos{\theta_0} \\ C_2 &= e\mu \sin{\theta_0}. \end{aligned}\]
Where \(e\) and \(\theta_0\) are new constants we have introduced and will explain once its relevance in \(r(\theta)\) becomes clearer. Therefore:
\[\begin{aligned} u(\theta) &= e\mu\cos{\theta_0}\cos{\theta} + e\mu\sin{\theta_0}\sin{\theta} + \mu \\ &= \mu\left(1+e\left[\cos{\theta_0}\cos{\theta} + \sin{\theta_0}\sin{\theta}\right]\right) \\ &= \mu\left(1+e\cos{(\theta-\theta_0)}\right). \end{aligned}\]
Hence:
\[\begin{aligned} r(\theta) &= \dfrac{1}{\mu\left(1+e\cos{(\theta-\theta_0)}\right)}. \end{aligned}\]
This is the equation for a conic section (parabola, hyperbola or ellipse) with \(e\) as its eccentricity and \(\theta_0\) is the angle at which the moving mass is closest to the central mass. If \(0 \leq e < 1\), it is an ellipse (\(e=0\) makes it a perfect circle); if \(e=1\), it is a parabola; and if \(e>1\), it is a hyperbola.

So this establishes to us that Lagrangian mechanics predicts that an object in orbit around a larger, central mass, will move in a conic section orbit. For the Moon's orbit around the Earth, \(e\) is also almost \(0\). For all the planets in the Solar System, their \(e\) values are between \(0\) and \(1\), giving them elliptical orbits, too.

Gravitational three-body problem

I thought a good example for you would be the gravitational three-body problem. As like the double pendulum problem, it exhibits chaos. Further, it is the premise of a popular scifi Netflix series 3 Body Problem, which is based on a novel called Remembrance of Earth's Past. As you can see in Figure , our axes are selected such that the mass \(M\) is centred at the origin. Consequently, the central mass does not move on our axes. So only the two other masses contribute to our system's kinetic energy:
\[\begin{aligned} T &= \dfrac{m_1}{2}(\dot{r}_1^2 + r_1^2 \dot{\theta}_1^2) + \dfrac{m_2}{2}(\dot{r}_2^2+r_2^2\dot{\theta}_2^2). \end{aligned}\]
I omitted the calculation of the velocity of the two moving bodies as they are identical to the velocity calculation for the two-body problem.

To calculate the potential energy, we will need to calculate \(r_{12}\), the distance between the masses \(m_1\) and \(m_2\). To calculate this, we will start with the \(x\) and \(y\) coordinates for the two moving masses:

\[\begin{aligned} x_1 &= r_1\cos{\theta_1} \\ y_1 &= r_1 \sin{\theta_1} \\ x_2 &= r_2 \cos{\theta_2} \\ y_2 &= r_2 \sin{\theta_2}. \end{aligned}\]
Hence the difference in \(x\) is \(r_2\cos{\theta_2} - r_1\cos{\theta_1}\) and the difference in \(y\) is \(r_2\sin{\theta_2}-r_1\sin{\theta_1}\). Hence:
\[\begin{aligned} r_{12}^2 &= (r_2\cos{\theta_2} - r_1\cos{\theta_1})^2 + (r_2\sin{\theta_2} - r_1\sin{\theta_1})^2 \\ &= r_2^2 \cos^2{\theta_2} + r_1^2 \cos^2{\theta_1} -2r_1 r_2 \cos{\theta_1}\cos{\theta_2} + r_2^2 \sin^2{\theta_2} + r_1^2\sin^2{\theta_1}-2r_1r_2 \sin{\theta_1}\sin{\theta_2} \\ &= r_1^2 + r_2^2 - 2r_1 r_2 \cos{(\theta_2-\theta_1)}. \end{aligned}\]
Square-rooting yields:
\[\begin{aligned} r_{12} &= \sqrt{r_1^2 + r_2^2 - 2r_1 r_2 \cos{(\theta_2-\theta_1)}}. \end{aligned}\]
We deliberately ignored the negative possibility as \(r_{12}\) is defined such that it must be non-negative. Hence the gravitational potential energy of our system:
\[\begin{aligned} V &= -\dfrac{GMm_1}{r_1} - \dfrac{GMm_2}{r_2} - \dfrac{Gm_1m_2}{r_{12}}. \end{aligned}\]
The first of these terms is the potential energy for the gravitational attraction between the central mass and \(m_1\). The second is the potential energy for the gravitational attraction between the central mass and \(m_2\). The third is the potential energy for the gravitational attraction between \(m_1\) and \(m_2\).

Hence the Lagrangian is:

\[\begin{align} L &= T - V \tag{34} \\ &= \dfrac{m_1}{2}(\dot{r}_1^2 + r_1^2 \dot{\theta}_1^2) + \dfrac{m_2}{2}(\dot{r}_2^2+r_2^2\dot{\theta}_2^2) + \dfrac{GMm_1}{r_1} + \dfrac{GMm_2}{r_2} + \dfrac{Gm_1m_2}{r_{12}}. \tag{35} \end{align}\]
We will calculate \(\dfrac{\partial r_{12}}{\partial q_i}\) as this will come in handy when finding \(\dfrac{\partial L}{\partial q_i}\).

For \(r_1\):

\[\begin{aligned} \dfrac{\partial r_{12}}{\partial r_1} &= \dfrac{2r_1-2r_2\cos{(\theta_2-\theta_1)}}{2\sqrt{r_1^2 + r_2^2 - 2r_1 r_2 \cos{(\theta_2-\theta_1)}}} \\ &= \dfrac{r_1-r_2\cos{(\theta_2-\theta_1)}}{\sqrt{r_1^2 + r_2^2 - 2r_1 r_2 \cos{(\theta_2-\theta_1)}}} \\ &= \dfrac{r_1-r_2\cos{(\theta_2-\theta_1)}}{r_{12}}. \end{aligned}\]
For \(r_2\):
\[\begin{aligned} \dfrac{\partial r_{12}}{\partial r_2} &= \dfrac{r_2-r_1\cos{(\theta_2-\theta_1)}}{r_{12}}. \end{aligned}\]
For \(\theta_1\):
\[\begin{aligned} \dfrac{\partial r_{12}}{\partial \theta_1} &= \dfrac{-2r_1r_2\sin{(\theta_2-\theta_1)}}{2r_{12}} \\ &= \dfrac{-r_1r_2\sin{(\theta_2-\theta_1)}}{r_{12}}. \end{aligned}\]
For \(\theta_2\):
\[\begin{aligned} \dfrac{\partial r_{12}}{\partial \theta_2} &= \dfrac{2r_1r_2\sin{(\theta_2-\theta_1)}}{2r_{12}} \\ &= \dfrac{r_1r_2\sin{(\theta_2-\theta_1)}}{r_{12}}. \end{aligned}\]
The canonical momentums are:
\[\begin{aligned} p_{r_1} &= \dfrac{\partial L}{\partial \dot{r}_1} \\ &= m_1 \dot{r}_1 \\ p_{r_2} &= \dfrac{\partial L}{\partial \dot{r}_2} \\ &= m_2 \dot{r}_2 \\ p_{\theta_1} &= \dfrac{\partial L}{\partial \dot{\theta}_1} \\ &= m_1 r_1^2\dot{\theta}_1 \\ p_{\theta_2} &= \dfrac{\partial L}{\partial \dot{\theta}_2} \\ &= m_2 r_2^2 \dot{\theta}_2. \end{aligned}\]
As for the spatial derivatives of \(L\):
\[\begin{aligned} \dfrac{\partial L}{\partial r_1} &= m_1 r_1 \dot{\theta}_1^2 - \dfrac{GMm_1}{r_1^2} - \dfrac{Gm_1 m_2}{r_{12}^2} \cdot \dfrac{\partial r_{12}}{\partial r_1} \\ &= m_1 r_1 \dot{\theta}_1^2 - \dfrac{GMm_1}{r_1^2}- \dfrac{Gm_1 m_2( r_1-r_2 \cos{(\theta_2-\theta_1)})}{r_{12}^3} \\ \dfrac{\partial L}{\partial r_2} &= m_2 r_2 \dot{\theta}_2^2 - \dfrac{GMm_2}{r_2^2} - \dfrac{Gm_1 m_2}{r_{12}^2} \cdot \dfrac{\partial r_{12}}{\partial r_2} \\ &= m_2 r_2 \dot{\theta}_2^2 - \dfrac{GMm_2}{r_2^2} - \dfrac{Gm_1 m_2( r_2-r_1 \cos{(\theta_2-\theta_1)})}{r_{12}^3} \\ \dfrac{\partial L}{\partial \theta_1} &= - \dfrac{Gm_1 m_2}{r_{12}^2} \cdot \dfrac{\partial r_{12}}{\partial \theta_1} \\ &= \dfrac{Gm_1 m_2 r_1r_2\sin{(\theta_2-\theta_1)}}{r_{12}^3} \\ \dfrac{\partial L}{\partial \theta_2} &= - \dfrac{Gm_1 m_2}{r_{12}^2} \cdot \dfrac{\partial r_{12}}{\partial \theta_2} \\ &= -\dfrac{Gm_1 m_2r_1r_2\sin{(\theta_2-\theta_1)}}{r_{12}^3}. \end{aligned}\]
Hence the \(r_1\) Euler-Lagrange equation is:
\[\begin{align} \dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{r}_1} &= \dfrac{\partial L}{\partial r_1} \tag{36} \\ m_1 \ddot{r}_1 &= m_1 r_1 \dot{\theta}_1^2 - \dfrac{GMm_1}{r_1^2} - \dfrac{Gm_1 m_2( r_1-r_2 \cos{(\theta_2-\theta_1)})}{r_{12}^3} \notag \\ \ddot{r}_1 &= r_1 \dot{\theta}_1^2 - \dfrac{GM}{r_1^2} - \dfrac{Gm_2( r_1-r_2 \cos{(\theta_2-\theta_1)})}{r_{12}^3}. \tag{37} \end{align}\]
Hence the \(r_2\) Euler-Lagrange equation is:
\[\begin{align} \dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{r}_2} &= \dfrac{\partial L}{\partial r_2} \tag{38} \\ m_2 \ddot{r}_2 &= m_2 r_2 \dot{\theta}_2^2 - \dfrac{GMm_2}{r_2^2} - \dfrac{Gm_1 m_2( r_2-r_1 \cos{(\theta_2-\theta_1)})}{r_{12}^3} \notag \\ \ddot{r}_2 &= r_2 \dot{\theta}_2^2 - \dfrac{GM}{r_2^2} - \dfrac{Gm_1( r_2-r_1 \cos{(\theta_2-\theta_1)})}{r_{12}^3}. \tag{39} \end{align}\]
As for the \(\theta_1\) Euler-Lagrange equation, it is:
\[\begin{aligned} \dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{\theta}_1} &= \dfrac{\partial L}{\partial \theta_1} \\ 2m_1 r_1\dot{r}_1 \dot{\theta}_1 + m_1 r_1^2 \ddot{\theta}_1 &= \dfrac{Gm_1 m_2 r_1r_2\sin{(\theta_2-\theta_1)}}{r_{12}^3}. \end{aligned}\]
Divide both sides by \(m_1r_1^2\):
\[\begin{align} \dfrac{2\dot{r}_1 \dot{\theta}_1}{r_1} + \ddot{\theta}_1 &= \dfrac{Gm_2 r_2\sin{(\theta_2-\theta_1)}}{r_1 r_{12}^3} \notag \\ \ddot{\theta}_1 &= -\dfrac{2\dot{r}_1 \dot{\theta}_1}{r_1} + \dfrac{Gm_2 r_2\sin{(\theta_2-\theta_1)}}{r_1 r_{12}^3}. \tag{40} \end{align}\]
As for \(\theta_2\):
\[\begin{aligned} \dfrac{d}{dt} \dfrac{\partial L}{\partial \dot{\theta}_2} &= \dfrac{\partial L}{\partial \theta_2} \\ 2m_2 r_2\dot{r}_2 \dot{\theta}_2 + m_2 r_2^2 \ddot{\theta}_2 &= \dfrac{Gm_1 m_2 r_1r_2\sin{(\theta_2-\theta_1)}}{r_{12}^3}. \end{aligned}\]
Dividing both sides by \(m_2r_2^2\):
\[\begin{align} \dfrac{2\dot{r}_2 \dot{\theta}_2}{r_2} + \ddot{\theta}_2 &= -\dfrac{Gm_1 r_1\sin{(\theta_2-\theta_1)}}{r_2 r_{12}^3} \notag \\ \ddot{\theta}_2 &= -\dfrac{2\dot{r}_2 \dot{\theta}_2}{r_2} -\dfrac{Gm_1 r_1\sin{(\theta_2-\theta_1)}}{r_2 r_{12}^3}. \tag{41} \end{align}\]

Equations (37), (39), (40) and (41) cannot be analytically solved, unlike the equations we obtained for the two-body problem. Consequently, we are forced to resort to numerical methods to solve this system.

Three-body problem simulation code. 
using DifferentialEquations
using Plots, Measures, Colors
using Printf, LaTeXStrings
ENV["GKSwstype"] = "100"
# ============================================================
# Three-body gravitational system
#
# Body M is fixed at the origin.
# Bodies m₁ and m₂ orbit M while also perturbing one another.
#
# Unlike a strongly hierarchical system, the masses here are
# comparable enough for the mutual interaction to produce
# strongly non-Keplerian and potentially chaotic motion.
#
# Units are normalised:
#   G = 1
#   mass = arbitrary mass unit
#   distance = arbitrary distance unit
#   time = corresponding dynamical time unit
# ============================================================

# ------------------------------------------------------------
# Parameters
# ------------------------------------------------------------

G              = 1.0
M              = 3.0
m₁             = 1.5
m₂             = 2.0
a₁             = 5.0
e₁             = 0.15
a₂             = 5.0
e₂             = 0.10
θ₁₀            = 0.0
θ₂₀            = π - 0.15
tspan          = (0.0, 200.0)
abstol         = 1e-11
reltol         = 1e-11
fps            = 60
marksize       = 10
stepsize       = 10/fps
legendfontsize = 24
guidefontsize  = 24
tickfontsize   = 20
titlefontsize  = 30

# ------------------------------------------------------------
# Initial approximate Keplerian orbits
# ------------------------------------------------------------

# Periapsis distances

r₁₀ = a₁ * (1 - e₁)
r₂₀ = a₂ * (1 - e₂)

# ------------------------------------------------------------
# Initial Keplerian periapsis velocities
# ------------------------------------------------------------

v₁₀ = sqrt(G * M * (1 + e₁) / r₁₀)
v₂₀ = sqrt(G * M * (1 + e₂) / r₂₀)

# Radial velocity is zero at periapsis.

ṙ₁₀ = 0.0
ṙ₂₀ = 0.0

# Since v = r θ̇:

θ̇₁₀ = v₁₀ / r₁₀
θ̇₂₀ = v₂₀ / r₂₀

# ------------------------------------------------------------
# Initial state vector
#
# u = [
#     r₁,
#     r₂,
#     θ₁,
#     θ₂,
#     ṙ₁,
#     ṙ₂,
#     θ̇₁,
#     θ̇₂
# ]
# ------------------------------------------------------------

u₀ = [
    r₁₀,
    r₂₀,
    θ₁₀,
    θ₂₀,
    ṙ₁₀,
    ṙ₂₀,
    θ̇₁₀,
    θ̇₂₀
]

# ------------------------------------------------------------
# Equations of motion
# ------------------------------------------------------------

function three_body!(du, u, p, t)

    r₁, r₂, θ₁, θ₂, ṙ₁, ṙ₂, θ̇₁, θ̇₂ = u

    Δθ = θ₂ - θ₁

    r₁₂ = sqrt(
        r₁^2 +
        r₂^2 -
        2*r₁*r₂*cos(Δθ)
    )

    # --------------------------------------------------------
    # Radial accelerations
    # --------------------------------------------------------

    r̈₁ =
        r₁*θ̇₁^2 -
        G*M/r₁^2 -
        G*m₂*(r₁ - r₂*cos(Δθ))/r₁₂^3

    r̈₂ =
        r₂*θ̇₂^2 -
        G*M/r₂^2 -
        G*m₁*(r₂ - r₁*cos(Δθ))/r₁₂^3

    # --------------------------------------------------------
    # Angular accelerations
    # --------------------------------------------------------

    θ̈₁ =
        -2*ṙ₁*θ̇₁/r₁ +
        G*m₂*r₂*sin(Δθ)/(r₁*r₁₂^3)

    θ̈₂ =
        -2*ṙ₂*θ̇₂/r₂ -
        G*m₁*r₁*sin(Δθ)/(r₂*r₁₂^3)

    # --------------------------------------------------------
    # First-order system
    # --------------------------------------------------------

    du[1] = ṙ₁
    du[2] = ṙ₂
    du[3] = θ̇₁
    du[4] = θ̇₂

    du[5] = r̈₁
    du[6] = r̈₂
    du[7] = θ̈₁
    du[8] = θ̈₂
end

# ------------------------------------------------------------
# Integrate
#
# 100 time units gives the system ample time to undergo
# several orbital periods and develop strongly perturbed
# trajectories.
# ------------------------------------------------------------

prob = ODEProblem(
    three_body!,
    u₀,
    tspan
)

solut = solve(
    prob,
    Vern8(),
    saveat=stepsize,
    abstol=abstol,
    reltol=reltol
)

# ------------------------------------------------------------
# Convert polar coordinates to Cartesian coordinates
# ------------------------------------------------------------

x₁ = solut[1, :] .* cos.(solut[3, :])
y₁ = solut[1, :] .* sin.(solut[3, :])

x₂ = solut[2, :] .* cos.(solut[4, :])
y₂ = solut[2, :] .* sin.(solut[4, :])

# ------------------------------------------------------------
# Calculate body-body separation
# ------------------------------------------------------------

separation = sqrt.(
    (x₂ .- x₁).^2 +
    (y₂ .- y₁).^2
)
# ------------------------------------------------------------
# Plot limits
# ------------------------------------------------------------

x_all = vcat(0.0, x₁, x₂)
y_all = vcat(0.0, y₁, y₂)

xmin = minimum(x_all)
xmax = maximum(x_all)
ymin = minimum(y_all)
ymax = maximum(y_all)

    ymax - ymin

yc = (ymin + ymax) / 2

xmax = xc + span/2 + margin

ymax = yc + span/2 + margin

Gravitational \(n\)-body problem

In this section, we will try to generalize our Lagrangian and system of equations from the previous section so that they are applicable to a gravitational system with an arbitrary number of bodies. Let \(M\) denote the static central mass, \(m_i\) the \(i\)th moving mass, \(r_i\) the distance from the central mass to the \(i\)th moving mass, \(\theta_i\) is the angle between the line formed by \(r_i\) and the positive \(x\)-axis, measured counter-clockwise. Which is essentially how we defined things in Figure .

So kinetic energy for this system should be pretty straight forward, namely it should simply be the sum of the kinetic energy of each individual body, in other words it should be:

\[\begin{aligned} T &= \sum_{i=1}^{n-1} \dfrac{m_i(\dot{r}_i^2+r_i^2\dot{\theta}_i^2)}{2}. \end{aligned}\]
Where \(m_i\) is the \(i\)th moving body. As for potential energy, well there will be terms for the interaction between each of the \(n\) bodies. For interactions between the central mass and the moving bodies, these will simply be of the form \(-\dfrac{GMm_i}{r_i}\). As for the interactions between the moving bodies, their potential energy terms will be of the form \(-\dfrac{Gm_i m_j}{r_{ij}}\) where \(r_{ij}\) is the distance between masses \(i\) and \(j\). Hence:
\[\begin{alignedat}{2} x_i &= r_i \cos{\theta_i},&\hspace{0.2cm}x_j &= r_j \cos{\theta_j} \\ y_i &= r_i \sin{\theta_i},&\hspace{0.2cm}y_j &= r_j \sin{\theta_j}. \end{alignedat}\]
Let us define the change in \(x\) between masses \(i\) and \(j\) as \(\Delta x_{ij}\) and the corresponding change in \(y\) is \(\Delta y_{ij}\).
\[\begin{aligned} \Delta x_{ij} &= r_j \cos{\theta_j} - r_i \cos{\theta_i} \\ \Delta y_{ij} &= r_j \sin{\theta_j} - r_i \sin{\theta_i}. \end{aligned}\]
Hence their squares would be:
\[\begin{aligned} \Delta x_{ij}^2 &= r_j^2 \cos^2{\theta_j} + r_i^2\cos^2{\theta_i} - 2r_ir_j \cos{\theta_i}\cos{\theta_j} \\ \Delta y_{ij}^2 &= r_j^2 \sin^2{\theta_j} + r_i^2\sin^2{\theta_i} - 2r_ir_j \sin{\theta_i}\sin{\theta_j}. \end{aligned}\]
Hence the squared distance between \(m_i\) and \(m_j\) is, by the Pythagorean theorem:
\[\begin{aligned} r_{ij}^2 &= \Delta x_{ij}^2 + \Delta y_{ij}^2 \\ &= r_j^2 \cos^2{\theta_j} + r_i^2\cos^2{\theta_i} - 2r_ir_j \cos{\theta_i}\cos{\theta_j} + r_j^2 \sin^2{\theta_j} + r_i^2\sin^2{\theta_i} - 2r_ir_j \sin{\theta_i}\sin{\theta_j} \\ &= r_i^2 (\cos^2{\theta_i}+\sin^2{\theta_i}) + r_j^2 (\cos^2{\theta_j}+\sin^2{\theta_j}) - 2r_i r_j (\cos{\theta_i}\cos{\theta_j} + \sin{\theta_i}\sin{\theta_j}) \\ &= r_i^2 + r_j^2 - 2r_i r_j \cos{(\theta_j-\theta_i)}. \end{aligned}\]
Square rooting yields:
\[\begin{aligned} r_{ij} &= \sqrt{r_i^2 + r_j^2 - 2r_i r_j \cos{(\theta_j-\theta_i)}}. \end{aligned}\]
As we can see, \(r_{ij} = r_{ji}\) due to cosine being an even function. Hence the potential energy is:
\[\begin{aligned} V &= -\sum_{i=1}^{n-1} \left(\dfrac{GMm_i}{r_i} + \sum_{j>i}^{n-1} \dfrac{Gm_i m_j}{r_{ij}}\right). \end{aligned}\]
Why the \(j>i\) on the second sum? Well, to ensure we do not count the same terms but with a different order of their indices (e.g. \(\dfrac{Gm_1 m_2}{r_{12}}\) and \(\dfrac{Gm_2 m_1}{r_{21}}\) are equivalent despite the different order of indices) twice. Hence:
\[\begin{aligned} L &= \sum_{i=1}^{n-1} \left(\dfrac{m_i (\dot{r}_i^2 + r_i^2 \dot{\theta}_i^2)}{2} + \dfrac{GMm_i}{r_i} + \sum_{j>i}^{n-1} \dfrac{Gm_i m_j}{r_{ij}}\right) \end{aligned}\]
Next we will calculate \(\dfrac{\partial r_{ij}}{\partial q_k}\). For \(q_k=r_k\):
\[\begin{aligned} \dfrac{\partial r_{ij}}{\partial r_k} &= \dfrac{2r_i \delta_{ik} + 2r_j \delta_{jk} - 2(\delta_{ik}r_j + r_i \delta_{jk})\cos{(\theta_j-\theta_i)}}{2r_{ij}} \\ &= \dfrac{r_i \delta_{ik} + r_j \delta_{jk} - (\delta_{ik}r_j + r_i \delta_{jk})\cos{(\theta_j-\theta_i)}}{r_{ij}} \\ &= \dfrac{\delta_{ik}(r_i - r_j\cos{(\theta_j-\theta_i)}) + \delta_{jk}(r_j -r_i \cos{(\theta_j-\theta_i)})}{r_{ij}}. \end{aligned}\]
As for \(q_k=\theta_k\):
\[\begin{aligned} \dfrac{\partial r_{ij}}{\partial \theta_k} &= \dfrac{2r_i r_j\sin{(\theta_j-\theta_i)}(\delta_{jk}-\delta_{ik})}{2r_{ij}} \\ &= \dfrac{r_i r_j\sin{(\theta_j-\theta_i)}(\delta_{jk}-\delta_{ik})}{r_{ij}}. \end{aligned}\]
Hence the canonical momentum for \(r_k\) is:
\[\begin{aligned} p_{r_k} &= \dfrac{\partial L}{\partial \dot{r}_k} \\ &= \sum_{i=1}^{n-1} \left(\dfrac{m_i (2\dot{r}_i \delta_{ik})}{2}\right) \\ &= m_k \dot{r}_k. \end{aligned}\]
Hence its time derivative is:
\[\begin{aligned} \dot{p}_{r_k} &= m_k \ddot{r}_k. \end{aligned}\]
As for the canonical momentum for \(\theta_k\), it is:
\[\begin{aligned} p_{\theta_k} &= \dfrac{\partial L}{\partial \dot{\theta}_k} \\ &= \sum_{i=1}^{n-1} \left(\dfrac{m_i (2r_i^2 \dot{\theta}_i \delta_{ik})}{2}\right) \\ &= m_k r_k^2 \dot{\theta}_k. \end{aligned}\]
Differentiating with respect to \(t\) yields:
\[\begin{aligned} \dot{p}_{\theta_k} &= 2m_k r_k \dot{r_k} \dot{\theta}_k + m r_k^2 \ddot{\theta}_k. \end{aligned}\]
As for \(\dfrac{\partial L}{\partial q_k}\):
\[\begin{aligned} \dfrac{\partial L}{\partial r_k} &= \sum_{i=1}^{n-1} \left(\dfrac{m_i (2r_i\delta_{ik} \dot{\theta}_i^2)}{2} - \dfrac{GMm_i\delta_{ik}}{r_i^2} - \sum_{j>i}^{n-1} \dfrac{Gm_i m_j\left(\delta_{ik}(r_i - r_j\cos{(\theta_j-\theta_i)}) + \delta_{jk}(r_j -r_i \cos{(\theta_j-\theta_i)})\right)}{r_{ij}^3}\right) \\ &= \sum_{i=1}^{n-1} \left(m_i \delta_{ik} \left[r_i \dot{\theta}_i^2 - \dfrac{GM}{r_i^2}\right] - \sum_{j>i}^{n-1} \dfrac{Gm_i m_j\left(\delta_{ik}(r_i - r_j\cos{(\theta_j-\theta_i)}) + \delta_{jk}(r_j -r_i \cos{(\theta_j-\theta_i)})\right)}{r_{ij}^3}\right) \\ &= m_k r_k \dot{\theta}_k^2 - \dfrac{GMm_k}{r_k^2} - \sum_{i=1}^{n-1}\sum_{j>i}^{n-1} \dfrac{Gm_i m_j\left(\delta_{ik}(r_i - r_j\cos{(\theta_j-\theta_i)}) + \delta_{jk}(r_j -r_i \cos{(\theta_j-\theta_i)})\right)}{r_{ij}^3}. \end{aligned}\]
The \(\delta_{ik}\) imposes that \(i=k\). Since \(j>i\) we get \(j=k+1, k+2, k+3, ..., n-1\). So we are left only with the \(j\) sum for terms multiplied by \(\delta_{ik}\). As for \(\delta_{jk}\), it imposes that \(j=k\) which then requires, given \(j>i\), that \(i=1,2,3,...,k-1\).
\[\begin{aligned} \sum_{i=1}^{n-1}\sum_{j>i}^{n-1} \dfrac{Gm_i m_j\left[\delta_{ik}(r_i - r_j \cos{(\theta_j-\theta_i)} )+ \delta_{jk}(r_j -r_i \cos{(\theta_j-\theta_i)})\right]}{r_{ij}^3} &= \sum_{j=k+1}^{n-1} \dfrac{Gm_{k}m_j (r_k-r_j\cos{(\theta_j-\theta_k)})}{r_{kj}^3} + \\ &\sum_{i=1}^{k-1} \dfrac{Gm_{i}m_k (r_k-r_i\cos{(\theta_k-\theta_i)})}{r_{ik}^3}. \end{aligned}\]
We can combine these sums into one, as \(r_{ij}=r_{ji}\) and \(\cos{(\theta_j-\theta_i)}=\cos{(\theta_i-\theta_j)}\):
\[\begin{aligned} \sum_{j=k+1}^{n-1} \dfrac{Gm_{k}m_j (r_k-r_j\cos{(\theta_j-\theta_k)})}{r_{kj}^3} + \sum_{i=1}^{k-1} \dfrac{Gm_{i}m_k (r_k-r_i\cos{(\theta_k-\theta_i)})}{r_{ik}^3} &= \sum_{\substack{i=1 \\ i\neq k}}^{n-1} \dfrac{Gm_{i}m_k (r_k-r_i\cos{(\theta_k-\theta_i)})}{r_{ik}^3}. \end{aligned}\]
Hence \(\dfrac{\partial L}{\partial r_k}\) becomes:
\[\begin{aligned} \dfrac{\partial L}{\partial r_k} &= m_k r_k \dot{\theta}_k^2 - \dfrac{GMm_k}{r_k^2} - \sum_{\substack{i=1 \\ i\neq k}}^{n-1} \dfrac{Gm_{i}m_k (r_k-r_i\cos{(\theta_k-\theta_i)})}{r_{ik}^3}. \end{aligned}\]
Hence the \(r_k\) equation of motion is:
\[\begin{aligned} m_k\ddot{r}_k &= m_k r_k \dot{\theta}_k^2 - \dfrac{GMm_k}{r_k^2} - \sum_{\substack{i=1 \\ i\neq k}}^{n-1} \dfrac{Gm_{i}m_k (r_k-r_i\cos{(\theta_k-\theta_i)})}{r_{ik}^3}. \end{aligned}\]
Dividing by \(m_k\) yields:
\[\begin{align} \ddot{r}_k &= r_k \dot{\theta}_k^2 - \dfrac{GM}{r_k^2} - \sum_{\substack{i=1 \\ i\neq k}}^{n-1} \dfrac{Gm_{i} (r_k-r_i\cos{(\theta_k-\theta_i)})}{r_{ik}^3}. \tag{42} \end{align}\]
As for \(\theta_k\), the canonical momentum and its time derivative are:
\[\begin{aligned} p_{\theta_k} &= \dfrac{\partial L}{\partial \dot{\theta}_k} \\ &= \sum_{i=1}^{n-1} \left(\dfrac{2m_i r_i^2 \dot{\theta}_i \delta_{ik}}{2}\right) \\ &= m_k r_k^2 \dot{\theta}_k. \end{aligned}\]
Hence the time derivative of \(p_{\theta_k}\) is:
\[\begin{aligned} \dot{p}_{\theta_k} &= 2m_kr_k \dot{r}_k \dot{\theta}_k + mr_k^2 \ddot{\theta}_k. \end{aligned}\]
As for the other component of Equations (20):
\[\begin{aligned} \dfrac{\partial L}{\partial \theta_k} &= -\sum_{i=1}^{n-1} \sum_{j>i}^{n-1} \dfrac{Gm_im_j}{r_{ij}^2} \dfrac{\partial r_{ij}}{\partial \theta_k} \\ &= -\sum_{i=1}^{n-1} \sum_{j>i}^{n-1} \dfrac{Gm_im_jr_i r_j\sin{(\theta_j-\theta_i)}(\delta_{jk}-\delta_{ik})}{r_{ij}^3} \\ &= \sum_{j=k+1}^{n-1}\dfrac{Gm_k m_jr_k r_j\sin{(\theta_j-\theta_k)}}{r_{kj}^3} - \sum_{i=1}^{k-1} \dfrac{Gm_i m_kr_i r_k\sin{(\theta_k-\theta_i)}}{r_{ik}^3} \\ &= \sum_{\substack{i=1\\ i\neq k}}^{n-1} \dfrac{Gm_i m_kr_i r_k\sin{(\theta_i-\theta_k)}}{r_{ik}^3}. \end{aligned}\]
Hence the Euler-Lagrange equations for \(\theta_k\) can be expressed as:
\[\begin{aligned} 2m_kr_k \dot{r}_k \dot{\theta}_k + mr_k^2 \ddot{\theta}_k &= \sum_{\substack{i=1\\i\neq k}}^{n-1} \dfrac{Gm_i m_kr_i r_k\sin{(\theta_i-\theta_k)}}{r_{ik}^3}. \end{aligned}\]
Dividing both sides by \(mr_k^2\) yields:
\[\begin{aligned} \dfrac{2\dot{r}_k\dot{\theta}_k}{r_k} + \ddot{\theta}_k &= \sum_{\substack{i=1\\i\neq k}}^{n-1} \dfrac{Gm_i r_i \sin{(\theta_i-\theta_k)}}{r_k r_{ik}^3}. \end{aligned}\]
Moving the first term on the left-hand side to the right-hand side yields:
\[\begin{align} \ddot{\theta}_k &= -\dfrac{2\dot{r}_k\dot{\theta}_k}{r_k} + \sum_{\substack{i=1\\i\neq k}}^{n-1} \dfrac{Gm_i r_i \sin{(\theta_i-\theta_k)}}{r_k r_{ik}^3}. \tag{43} \end{align}\]

Three-body problem comparison

An important verification of our working is that if \(n=3\), we should get the same equations as we obtained in gravitational three-body problem. If \(n=3\), we get for \(\ddot{r}_1\):

\[\begin{aligned} \ddot{r}_1 &= r_1\dot{\theta}_1^2 - \dfrac{GM}{r_1^2} - \dfrac{Gm_2(r_1 - r_2\cos{(\theta_1-\theta_2)})}{r_{12}^3} \\ &= r_1\dot{\theta}_1^2 - \dfrac{GM}{r_1^2} - \dfrac{Gm_2(r_1 - r_2\cos{(\theta_2-\theta_1)})}{r_{12}^3}. \end{aligned}\]
This matches Equation (37). As for \(\ddot{r}_2\):
\[\begin{aligned} \ddot{r}_2 &= r_2\dot{\theta}_2^2 - \dfrac{GM}{r_2^2} - \dfrac{Gm_2(r_2 - r_1\cos{(\theta_2-\theta_1)})}{r_{12}^3}. \end{aligned}\]
Which matches Equation (39). As for \(\ddot{\theta}_1\):
\[\begin{aligned} \ddot{\theta}_1 &= -\dfrac{2\dot{r}_1\dot{\theta}_1}{r_1} + \dfrac{Gm_2r_2 \sin{(\theta_2-\theta_1)}}{r_1 r_{12}^3}. \end{aligned}\]
Which matches Equation (40). As for \(\ddot{\theta}_2\):
\[\begin{aligned} \ddot{\theta}_2 &= -\dfrac{2\dot{r}_2\dot{\theta}_2}{r_2} + \dfrac{Gm_1r_1 \sin{(\theta_1-\theta_2)}}{r_2 r_{12}^3} \\ &= -\dfrac{2\dot{r}_2\dot{\theta}_2}{r_2} - \dfrac{Gm_1r_1 \sin{(\theta_2-\theta_1)}}{r_2 r_{12}^3}. \end{aligned}\]
Which matches Equation (41). Hence our \(n\)-body problem equations match our three-body problem equations when \(n=3\).

N-body problem simulation code. 
using DifferentialEquations
using Plots, Measures, Colors
using Printf, LaTeXStrings
ENV["GKSwstype"] = "100"

# ============================================================
# N-body gravitational system with a fixed central mass
#
# M is fixed at the origin.
# N orbiting bodies interact gravitationally with M and with
# one another.
#
# State vector:
# u = [r₁,...,rₙ, θ₁,...,θₙ, ṙ₁,...,ṙₙ, θ̇₁,...,θ̇ₙ]
#
# All quantities use normalized units.
# ============================================================

# ------------------------------------------------------------
# Parameters
# ------------------------------------------------------------
# Add or remove entries to change the number of orbiting bodies.
# All parameter vectors must have the same length.
G              = 1.0
M              = 3.0
masses         = [1.5, 2.0, 0.01]
N              = length(masses)
# Initial conditions
## Semi-major axes
a              = [5.0, 5.0, 15.0]
## Eccentricities
e              = [0.20, 0.05, 0.01]
## Initial angular positions
θ₀             = [
    0.0
    π - 0.15
    π/3 + 0.06
]
# Frames per second of animation
fps            = 60
# Solution params
tspan          = (0.0, 60.0)
abstol         = 1e-11
reltol         = 1e-11
stepsize       = 8/fps
# Animation params
marksize       = 10
legendfontsize = 24
guidefontsize  = 24
tickfontsize   = 20
titlefontsize  = 30

# ------------------------------------------------------------
# Validate parameters
# ------------------------------------------------------------
@assert N >= 1 "At least one orbiting body is required."
@assert length(a) == N "The semimajor axis vector must have N entries."
@assert length(e) == N "The eccentricity vector must have N entries."
@assert all(>(0), masses) "All orbiting masses must be positive."
@assert all(>(0), a) "All semimajor axes must be positive."
@assert all(x -> 0 <= x < 1, e) "Eccentricities must satisfy 0 ≤ e < 1."

# ------------------------------------------------------------
# Initial approximate Keplerian orbits
# ------------------------------------------------------------

# Periapsis distances

r₀ = a .* (1 .- e)

# Initial Keplerian periapsis velocities

v₀ = sqrt.(G .* M .* (1 .+ e) ./ r₀)

# Radial velocities vanish at periapsis.

ṙ₀ = zeros(N)

# Since v = r θ̇:

θ̇₀ = v₀ ./ r₀

# ------------------------------------------------------------
# Initial state vector
# ------------------------------------------------------------

u₀ = vcat(
    r₀,
    θ₀,
    ṙ₀,
    θ̇₀
)

# ------------------------------------------------------------
# Equations of motion
# ------------------------------------------------------------

function n_body!(du, u, p, t)

    G, M, masses, N = p

    # Obtain views of the state vector.

    r  = @view u[1:N]
    θ  = @view u[N+1:2N]
    ṙ = @view u[2N+1:3N]
    θ̇ = @view u[3N+1:4N]

    # Obtain views of the derivative vector.

    dr  = @view du[1:N]
    dθ  = @view du[N+1:2N]
    dṙ = @view du[2N+1:3N]
    dθ̇ = @view du[3N+1:4N]

    # First-order kinematic equations.

    dr .= ṙ
    dθ .= θ̇

    # --------------------------------------------------------
    # Gravitational accelerations
    # --------------------------------------------------------

    for k in 1:N

        # Angular differences relative to body k.

        Δθ = θ .- θ[k]

        # Distances between body k and every other body.

        rᵢₖ = sqrt.(
            r[k]^2 .+
            r.^2 .-
            2 .* r[k] .* r .* cos.(Δθ)
        )

        # Exclude self-interaction.

        rᵢₖ[k] = Inf

        # ----------------------------------------------------
        # Radial acceleration
        # ----------------------------------------------------

        radial_interaction = sum(
            masses .* (
                r[k] .- r .* cos.(Δθ)
            ) ./ rᵢₖ.^3
        )

        r̈ₖ =
            r[k]*θ̇[k]^2 -
            G*M/r[k]^2 -
            G*radial_interaction

        # ----------------------------------------------------
        # Angular acceleration
        # ----------------------------------------------------

        angular_interaction = sum(
            masses .* r .* sin.(Δθ) ./ rᵢₖ.^3
        )

        θ̈ₖ =
            -2*ṙ[k]*θ̇[k]/r[k] +
            G*angular_interaction/r[k]

        dṙ[k] = r̈ₖ
        dθ̇[k] = θ̈ₖ

    end
end

# ------------------------------------------------------------
# Integrate
# ------------------------------------------------------------

p = (G, M, masses, N)

prob = ODEProblem(
    n_body!,
    u₀,
    tspan,
    p
)

solut = solve(
    prob,
    Vern8(),
    saveat=stepsize,
    abstol=abstol,
    reltol=reltol
)

# ------------------------------------------------------------
# Convert polar coordinates to Cartesian coordinates
# ------------------------------------------------------------

x = [
    solut[k, :] .* cos.(solut[N+k, :])
    for k in 1:N
]

y = [
    solut[k, :] .* sin.(solut[N+k, :])
    for k in 1:N
]

# ------------------------------------------------------------
# Calculate pairwise separations
# ------------------------------------------------------------

separations = Dict{Tuple{Int,Int},Vector{Float64}}()

for k in 1:N-1
    for i in k+1:N

        separations[(k,i)] = sqrt.(
            (x[k] .- x[i]).^2 .+
            (y[k] .- y[i]).^2
        )

    end
end

# ------------------------------------------------------------

y_all = vcat([0.0], y...)

xmin = minimum(x_all)
xmax = maximum(x_all)
ymin = minimum(y_all)
ymax = maximum(y_all)

span = max(xmax - xmin, ymax - ymin)

margin = 0.08 * span

xc = (xmin + xmax)/2
yc = (ymin + ymax)/2

xmin = xc - span/2 - margin
xmax = xc + span/2 + margin

ymin = yc - span/2 - margin
ymax = yc + span/2 + margin

# Colours
# ------------------------------------------------------------

palette = [
    RGB(0.0, 0.0, 0.65),   # Dark blue
    RGB(0.0, 0.55, 0.55),  # Dark teal
    RGB(0.65, 0.0, 0.0),   # Dark red

    RGB(0.0, 0.45, 0.15),  # Dark green
    RGB(0.65, 0.25, 0.0),  # Dark orange
    RGB(0.25, 0.25, 0.25), # Dark grey
    RGB(0.0, 0.4, 0.65)    # Steel blue
]

Hamiltonian mechanics

In Hamiltonian mechanics, we can usually define the Hamiltonian as:

\[\begin{align} H &= T + V. \tag{44} \end{align}\]
Which is the total energy of our system. More generally we define the Hamiltonian as:
\[\begin{align} H &\stackrel{\text{def}}{=} \sum_{i=1}^n p_i \dot{q}_i - L. \tag{45} \end{align}\]
Equation (45) is called the Legendre transformation of the Lagrangian. So when are Equations (44) and (45) not equivalent? The answer is when our potential energy depends, at least in part, on the generalized velocities. Another difference from Lagrangian mechanics is that we define \(H\) in terms of \(p_i\) and \(q_i\) instead of \(q_i\) and \(\dot{q}_i\).

So what is the Legendre transformation? It takes a function, say \(f(x)\), and it uses its tangent lines and their \(y\) intercepts to create a new function, \(g(p)\) that incorporates all the information that \(f(x)\) contained. Here is a great video that explains the Legendre transformation and its derivation.

The equations of motion with no non-conservative forces are:

\[\begin{align} \dot{p}_i &= -\dfrac{\partial H}{\partial q_i} \tag{46} \\ \dot{q}_i &= \dfrac{\partial H}{\partial p_i}. \tag{47} \end{align}\]
We can derive these equations of motion by considering an infinitesimal change to our path and its effect on \(H\), which we will denote as \(dH\):
\[\begin{align} dH &= \sum_{i=1}^n d(p_i\dot{q}_i) - dL \tag{48} \\ &= \sum_{i=1}^n dp_i \dot{q}_i + p_i d\dot{q}_i - dL \tag{49} \\ &= \sum_{i=1}^n \dot{q}_i dp_i + p_i d\dot{q}_i - \dfrac{\partial L}{\partial q_i} dq_i - \dfrac{\partial L}{\partial \dot{q}_i}d\dot{q}_i. \notag \end{align}\]
To go from Equations (48) to (49), we used the product rule of differentiation, in case you were wondering. Next we use the definition of canonical momentum:
\[\begin{aligned} dH &= \sum_{i=1}^n \dot{q}_i dp_i + p_i d\dot{q}_i - \dfrac{\partial L}{\partial q_i} dq_i - p_i d\dot{q}_i \\ &= \sum_{i=1}^n \dot{q}_i dp_i - \dfrac{\partial L}{\partial q_i} dq_i \\ &= \sum_{i=1}^n - \dfrac{\partial L}{\partial q_i} dq_i + \dot{q}_i dp_i. \end{aligned}\]
Next we can use Equations (20) to simplify our \(\dfrac{\partial L}{\partial q_i}\) term. As remember this, according to Equations (20) is equal to \(\dfrac{d}{dt}\dfrac{\partial L}{\partial \dot{q}_i}\) which can also be written as \(\dot{p}_i\):
\[\begin{align} dH &= \sum_{i=1}^n \dot{q}_i dp_i - \dot{p}_i dq_i. \tag{50} \end{align}\]
Assuming our Hamiltonian does not explicitly depend on \(t\), we can also write \(dH\) as:
\[\begin{align} dH &= \sum_{i=1}^n \dfrac{\partial H}{\partial q_i} dq_i + \dfrac{\partial H}{\partial p_i}dp_i. \tag{51} \end{align}\]
As this is just the change in \(H\) caused directly by the change in \(q_i\) plus the change in \(H\) that is directly caused by the change in \(p_i\). Equating like terms in the right-hand sides of Equations (50) and (51) yields:
\[\begin{aligned} \dot{p}_i &= -\dfrac{\partial H}{\partial q_i} \\ \dot{q}_i &= \dfrac{\partial H}{\partial p_i}. \end{aligned}\]
Which are Equations (46) and (47), which are known as Hamilton's equations. I should mention this is not the only way to derive Hamilton's equations; it is also possible to derive them directly from the stationary action principle, for instance.

To account for non-conservative forces, we merely add the corresponding generalized force terms to the right-hand side of Equation (46). In other words:

\[\begin{align} \dot{p}_i &= -\dfrac{\partial H}{\partial q_i} + Q_i. \tag{52} \end{align}\]
This creates a new kind of space that we can visualize our solution on that has dimensions \(q_i\) and \(p_i\). This type of space is known as phase space.

Examples

Simple pendulum

The Hamiltonian for the simple pendulum is:

\[\begin{align} H &= T + V \tag{53} \\ &= \dfrac{ml^2 \dot{\theta}^2}{2} + mgl\sin{\theta}. \tag{54} \end{align}\]
We can use Equation (44) to determine our Hamiltonian here because our potential energy, \(V\), is independent of the generalized velocities. Problem is, however, that this is written in terms of \(q_i\) and \(\dot{q}_i\) not \(q_i\) and \(p_i\). First we need to determine what our canonical momentum is. Equations (24) yields:
\[\begin{align} p_{\theta} &= \dfrac{\partial L}{\partial \dot{\theta}} \notag \\ p_{\theta} &= ml^2\dot{\theta}. \tag{55} \end{align}\]
Rewriting Equation (55) with \(\dot{\theta}\) as its subject:
\[\begin{align} \dot{\theta} &= \dfrac{p_{\theta}}{ml^2}. \tag{56} \end{align}\]
Substituting Equation (59) into Equation (54) yields:
\[\begin{aligned} H &= \dfrac{ml^2}{2} \left( \dfrac{p_{\theta}}{ml^2} \right)^2 + mgl\sin{\theta} \\ &= \dfrac{ml^2}{2} \dfrac{p_{\theta}^2}{m^2l^4} + mgl\sin{\theta}. \end{aligned}\]
Cancelling out common factors in the numerator and denominator of the kinetic energy term yields:
\[\begin{align} H &= \dfrac{p_{\theta}^2}{2ml^2} + mgl\sin{\theta}. \tag{57} \end{align}\]
Hence the equations of motion are:
\[\begin{align} \dot{p}_{\theta} &= -\dfrac{\partial H}{\partial \theta} \notag \\ &= - mgl\cos{\theta} \tag{58} \\ \dot{\theta} &= \dfrac{\partial H}{\partial p_{\theta}} \notag \\ &= \dfrac{p_{\theta}}{ml^2}. \tag{59} \end{align}\]
As we can see, Hamiltonian mechanics yields a series of first-order ordinary differential equations (ODEs) instead of second-order ODEs. Which is important because Lagrangian mechanics and Newtonian mechanics both yield second-order ODE systems. That being said, if you rewrite Equation (59) to make \(p_{\theta}\) its subject and substitute it into Equation (58) and rearrange it to make \(\ddot{\theta}\) the subject, you will obtain Equation (29).

Projectile motion

Let us analyse what happens when a projectile is fired into the air. Let \(x\) represent the horizontal direction and \(y\) represent the vertical direction. Our potential energy here would be \(mgy\), hence it is independent of the generalized velocities and we can use the \(H=T+V\) definition of the Hamiltonian.

\[\begin{aligned} H &= \dfrac{m}{2}(\dot{x}^2+\dot{y}^2) + mgy. \end{aligned}\]
As for our canonical momentum:
\[\begin{alignedat}{2} p_x &= m\dot{x} \hspace{0.2cm}\implies \dot{x} &&= \dfrac{p_x}{m} \\ p_y &= m\dot{y} \hspace{0.2cm}\implies \dot{y} &&= \dfrac{p_y}{m}. \end{alignedat}\]
Hence our Hamiltonian can be rewritten as:
\[\begin{aligned} H &= \dfrac{p_x^2+p_y^2}{2m} + mgy. \end{aligned}\]
As for air resistance it could be approximated by:
\[\begin{aligned} \mathbf{F}_D &= -\dfrac{\rho C_D A|v|\textbf{v}}{2} \\ &= -\dfrac{\rho C_D A\sqrt{\dot{x}^2+\dot{y}^2}}{2} (\dot{x}, \dot{y}). \end{aligned}\]
As for our covariant basis vectors they are, since we are using Cartesian coordinates:
\[\begin{aligned} \dfrac{\partial \mathbf{r}}{\partial x} &= (1, 0) \\ \dfrac{\partial \mathbf{r}}{\partial y} &= (0, 1). \end{aligned}\]
Hence our generalized non-conservative forces are:
\[\begin{aligned} Q_x &= -\dfrac{\rho C_D A\sqrt{\dot{x}^2+\dot{y}^2}}{2} (\dot{x}, \dot{y}) \cdot (1,0) \\ &= -\dfrac{\rho C_D A\dot{x}\sqrt{\dot{x}^2+\dot{y}^2}}{2} \\ &= -\dfrac{\rho C_D A\dfrac{p_x}{m}\sqrt{\dfrac{p_x^2}{m^2}+\dfrac{p_y^2}{m^2}}}{2} \\ &= -\dfrac{\rho C_D A p_x\sqrt{p_x^2+p_y^2}}{2m^2} \\ Q_y &= -\dfrac{\rho C_D A\sqrt{\dot{x}^2+\dot{y}^2}}{2} (\dot{x}, \dot{y}) \cdot (0, 1) \\ &= -\dfrac{\rho C_D A\dot{y}\sqrt{\dot{x}^2+\dot{y}^2}}{2} \\ &= -\dfrac{\rho C_D A\dfrac{p_y}{m}\sqrt{\dfrac{p_x^2}{m^2}+\dfrac{p_y^2}{m^2}}}{2} \\ &= -\dfrac{\rho C_D A p_y\sqrt{p_x^2+p_y^2}}{2m^2}. \end{aligned}\]
Our equations of motion are:
\[\begin{aligned} \dot{x} &= \dfrac{\partial H}{\partial p_x} \\ \dot{y} &= \dfrac{\partial H}{\partial p_y} \\ \dot{p}_x &= -\dfrac{\partial H}{\partial x} + Q_x \\ \dot{p}_y &= -\dfrac{\partial H}{\partial y} + Q_y. \end{aligned}\]
Hence for projectile motion they become:
\[\begin{align} \dot{x} &= \dfrac{p_x}{m} \tag{63} \\ \dot{y} &= \dfrac{p_y}{m} \tag{64} \\ \dot{p}_x &= -\dfrac{\rho C_D A p_x\sqrt{p_x^2+p_y^2}}{2m^2} \tag{65} \\ \dot{p}_y &= -mg -\dfrac{\rho C_D A p_y\sqrt{p_x^2+p_y^2}}{2m^2}. \tag{66} \end{align}\]

Poisson brackets

Poisson brackets provide us an elegant and powerful way to rewrite Hamilton's equations. If we have \(n\) degrees of freedom and two functions \(f\) and \(g\) that depend on \(p_i\) and \(q_i\):[1]

\[\begin{align} \{f, g\} &\stackrel{\text{def}}{=} \sum_{i=1}^n \left( \dfrac{\partial f}{\partial q_i} \dfrac{\partial g}{\partial p_i} - \dfrac{\partial f}{\partial p_i}\dfrac{\partial g}{\partial q_i} \right). \tag{67} \end{align}\]

Poisson brackets also have several interesting properties, such as antisymmetry:

\[\begin{align} \{A, B\} &= -\{B, A\}. \tag{68} \end{align}\]
Consequently:
\[\begin{align} \{A,A\} &= 0. \tag{69} \end{align}\]
Further, assuming each of the coordinates of the phase space are independent, it follows that:
\[\begin{align} \{q_j, p_k\} &= \sum_{i=1}^n \left( \dfrac{\partial q_j}{\partial q_i} \dfrac{\partial p_k}{\partial p_i} - \dfrac{\partial q_j}{\partial p_i} \dfrac{\partial p_k}{\partial q_i} \right) \notag \\ &= \sum_{i=1}^n \delta_{ij}\delta_{ik} \notag \\ &= \delta_{jk}. \tag{70} \end{align}\]
Above we used \(\delta_{ik}\) to denote the Kronecker delta function. It is equal to one if its arguments are equal and zero otherwise.
\[\begin{align} \{q_j, q_k\} &= \sum_{i=1}^n \left( \dfrac{\partial q_j}{\partial q_i} \dfrac{\partial q_k}{\partial p_i} - \dfrac{\partial q_j}{\partial p_i} \dfrac{\partial q_k}{\partial q_i} \right) \notag \\ &= 0 \tag{71} \\ \{p_j, p_k\} &= \sum_{i=1}^n \left(\dfrac{\partial p_j}{\partial q_i}\dfrac{\partial p_k}{\partial p_i} - \dfrac{\partial p_j}{\partial p_i}\dfrac{\partial p_k}{\partial q_i}\right) \notag \\ &= 0. \tag{72} \end{align}\]
The quality of two functions, say \(f\) and \(g\), having a Poisson bracket that equals zero is phrased as \(f\) and \(g\) commuting under the Poisson bracket.

If a function \(f(q_i, p_i)\) is not explicitly dependent on \(t\) and only depends on \(t\) indirectly through \(q_i\) and \(p_i\), then, via the chain rule:

\[\begin{align} \dfrac{df}{dt} &= \sum_{i=1}^n \dfrac{\partial f}{\partial q_i}\dfrac{d q_i}{dt} + \dfrac{\partial f}{\partial p_i}\dfrac{dp_i}{dt}. \tag{73} \end{align}\]
We can use Hamilton's equations to replace \(\dfrac{dq_i}{dt}\) and \(\dfrac{dp_i}{dt}\):
\[\begin{align} \dfrac{df}{dt} &= \sum_{i=1}^n \dfrac{\partial f}{\partial q_i}\dfrac{\partial H}{\partial p_i} - \dfrac{\partial f}{\partial p_i}\dfrac{\partial H}{\partial q_i}. \tag{74} \end{align}\]
Interestingly, the right-hand side is equal to the Poisson bracket of \(f\) with \(H\), in other words:
\[\begin{align} \dfrac{df}{dt} &= \{f, H\}. \tag{75} \end{align}\]
Hence commuting with the Hamiltonian under the Poisson bracket is a sufficient condition for a quantity that does not explicitly depend on time to have a zero time derivative. A zero time derivative means the quantity is static over time which means it is conserved.

This quality makes it unsurprising that Hamilton's equations can be rewritten as:

\[\begin{align} \dot{q}_k &= \{q_k, H\} \tag{76} \\ \dot{p}_k &= -\{p_k, H\}. \tag{77} \end{align}\]

Noether's theorem

Noether's theorem essentially states that for every continuous symmetry in the Lagrangian, there is a corresponding conservation law. For instance, time translation symmetry of the Lagrangian yields the conservation of energy. To show this, we will assume our Lagrangian does not explicitly depend on \(t\). That is, \(t\) itself does not appear directly in our Lagrangian. The only time dependence \(L\) has on \(t\) is through the dependence of \(q_i\) and \(\dot{q}_i\) on time. If the Lagrangian did explicitly depend on time, we would expect it not to have time translation symmetry. Say we increase time according to the transformation: \(t\rightarrow t+dt\) where \(dt\) is an infinitesimal change in \(t\).

\[\begin{align} L(q_i(t+dt), \dot{q}_i(t+dt)) &= L(q_i(t), \dot{q}_i(t)) + \dfrac{dL}{dt} dt \tag{78} \\ &= L(q_i(t), \dot{q}_i(t)) + \sum_{i=1}^n\dfrac{\partial L}{\partial q_i} \dfrac{dq_i}{dt} dt + \dfrac{\partial L}{\partial \dot{q}_i} \dfrac{d\dot{q}_i}{dt} dt . \tag{79} \end{align}\]
Subtracting \(L(q_i(t), \dot{q}_i(t))\) from both sides of Equation (79) yields:
\[\begin{align} L(q_i(t+dt), \dot{q}_i(t+dt)) - L(q_i(t), \dot{q}_i(t)) &= \sum_{i=1}^n\dfrac{\partial L}{\partial q_i} \dfrac{dq_i}{dt} dt + \dfrac{\partial L}{\partial \dot{q}_i} \dfrac{d\dot{q}_i}{dt} dt. \tag{80} \end{align}\]
We will call the left-hand side of Equation (80) \(dL\), hence Equation (80) becomes:
\[\begin{align} dL &= \sum_{i=1}^n \dfrac{\partial L}{\partial q_i} \dfrac{dq_i}{dt} dt + \dfrac{\partial L}{\partial \dot{q}_i} \dfrac{d\dot{q}_i}{dt} dt. \tag{81} \end{align}\]
Rearranging Equations (20) yields that:
\[\begin{align} \dfrac{\partial L}{\partial q_i} = \dfrac{d}{dt}\left(\dfrac{\partial L}{\partial \dot{q}_i}\right). \tag{82} \end{align}\]
If you are wondering what about if we have non-conservative forces? Would that not mean Equations (82) would not hold as there would be a missing generalized force term? Yes and in that event the Lagrangian would indeed change in time and conservation of energy would not hold, as our system would be losing energy to those non-conservative forces.

Substituting Equations (82) into Equation (81) yields:

\[\begin{align} dL &= \sum_{i=1}^n dt\left(\dfrac{d}{dt}\dfrac{\partial L}{\partial \dot{q}_i}\dot{q}_i + \dfrac{\partial L}{\partial \dot{q}_i}\ddot{q}_i\right). \tag{83} \end{align}\]
Substituting Equations (24) into Equation (83) yields:
\[\begin{align} dL &= dt\sum_{i=1}^n \left(\dfrac{dp_i}{dt} \dot{q}_i + p_i \ddot{q}_i\right) \notag \\ &= dt\sum_{i=1}^n \left(\dot{p}_i \dot{q}_i + p_i \ddot{q}_i\right). \tag{84} \end{align}\]
We can rewrite the bracketed expression on the right-hand side of Equation (84) using the product rule of differentiation as:
\[\begin{aligned} dL &= dt\sum_{i=1}^n \dfrac{d}{dt}\left(p_i \dot{q}_i\right) \\ &= dt\dfrac{d}{dt}\sum_{i=1}^n p_i \dot{q}_i. \end{aligned}\]
If \(L\) does not change in time, \(\Delta L=0\), and hence:
\[\begin{align} dt \dfrac{d}{dt} \sum_{i=1}^n p_i \dot{q}_i &= 0. \tag{85} \end{align}\]
Dividing both sides of Equations (85) by \(dt\) yields:
\[\begin{aligned} \dfrac{d}{dt} \sum_{i=1}^n p_i \dot{q}_i &= 0. \end{aligned}\]
\(L\) does not change, so \(\dfrac{dL}{dt}=0\), too. Hence:
\[\begin{align} \dfrac{d}{dt} \left(\sum_{i=1}^n p_i \dot{q}_i - L\right) &= 0. \tag{86} \end{align}\]
We could now use Equation (45) to simplify Equation (86), but I would like to use this as an opportunity to show you how Equations (44) and (45) are usually equivalent. Interestingly, \(\displaystyle\sum_{i=1}^n p_i \dot{q}_i=2T\), that is it is twice the kinetic energy of our system. We can establish this identity using Euler's theorem for homogeneous functions.

Say we have a homogeneous function \(f\) of degree \(m\) of the form:

\[\begin{aligned} f = a_{m+1,1,1,...,1} x_1^m + a_{m,2,1,...,1}x_1^{m-1}x_2 + a_{m-1,2,2,...,1}x_1^{m-2}x_2 x_3 + ... + a_{1,m+1,1,...,1}x_2^m + ... + a_{1, 1, 1, ..., m+1}x_n^m \end{aligned}\]
where \(a_{i,j,k,...,}\) are coefficients that do not depend on our variables. In other words, \(f\) is a polynomial function of \(x_i\) (\(i\in\{1, 2, 3, ..., n\}\)) with a maximum total power of \(m\). Then Euler's theorem states that:[2]
\[\begin{align} \sum_{i=1}^n x_i \dfrac{\partial f}{\partial x_i} &= mf. \tag{87} \end{align}\]
Kinetic energy is a homogeneous function, in terms of \(\dot{q}_i\), of second order, specifically it can be written as:
\[\begin{align} T &= \sum_{i=1}^n \sum_{j=1}^n a_{ij} \dot{q}_i \dot{q}_j. \tag{88} \end{align}\]
Here also \(a_{ij}\) refers to coefficients that do not depend on \(\dot{q}_i\). Hence:
\[\begin{align} \sum_{i=1}^n \dot{q}_i \dfrac{\partial T}{\partial \dot{q}_i} &= 2T. \tag{89} \end{align}\]
If we assume that potential energy is independent of \(\dot{q}_i\), then:
\[\begin{align} \dfrac{\partial L}{\partial \dot{q}_i}&=\dfrac{\partial T}{\partial \dot{q}_i}. \tag{90} \end{align}\]
Plugging Equations (90) into Equations (89) gives:
\[\begin{align} \sum_{i=1}^n \dot{q}_i \dfrac{\partial L}{\partial \dot{q}_i} &= 2T. \tag{91} \end{align}\]
Substituting Equations (24) into Equations (91) we get:
\[\begin{align} \sum_{i=1}^n p_i \dot{q}_i &= 2T \tag{92} \end{align}\]

Hence if we substitute Equation (19) into Equation (86), we obtain:

\[\begin{align} \dfrac{d}{dt} \left(2T-(T-V)\right) &= 0 \notag \\ \dfrac{d}{dt} \left(T+V\right) &= 0. \tag{93} \end{align}\]
Hence substituting Equation (44) into Equation (93) yields:
\[\begin{align} \dfrac{dH}{dt} &= 0. \tag{94} \end{align}\]
So we see that Equations (44) and (45) are equivalent if and only if potential energy is independent of generalized velocity. We also obtain that the Hamiltonian — which is the total energy of the system if potential energy is independent of generalized velocity — does not change when the Lagrangian is time symmetric, hence it is conserved.

I should also mention that the Hamiltonian formulation of Noether's theorem uses Equation (75). As if a quantity that does not explictly depend on time commutes with the Hamiltonian under the Poisson bracket, this means it does not change over time and hence is conserved.

Hamilton-Jacobi equation

There is a final formulation of classical mechanics that I should probably cover. It is based around the so called Hamilton-Jacobi equation which is of the form:

\[\begin{align} \dfrac{\partial S}{\partial t} + H\left(q_i, \dfrac{\partial S}{\partial q_i}, t\right) &= 0. \tag{95} \end{align}\]
Where \(S\) is the action, which is also called Hamilton's principal function. In this approach, we essentially write our Hamiltonian in terms of \(p_i\) and \(q_i\) and then replace the \(p_i\) with \(\dfrac{\partial S}{\partial q_i}\). If our Hamiltonian does not explicitly depend on time, which is usually the case, we then use a separation of variables of the form:
\[\begin{align} S(q_i, t) &= W(q_i)-Et. \tag{96} \end{align}\]
Where \(W\) is called Hamilton's characteristic function or the abbreviated action and \(E\) is the constant energy.

This approach to mechanics actually lead directly to the Schrödinger equation. Schrödinger actually derived his equation from the Hamilton-Jacobi equation. Why? Well, out of the formulations of classical mechanics, the Hamilton-Jacobi equation allows us to describe mechanical systems in a way that is analogous to light waves. The wave-particle duality — the idea that every quantum particle, including electrons and photons, exhibit both wave and particle properties — is a fundamental part of quantum mechanics and hence the Hamilton-Jacobi equation provides a particularly natural starting point for the development of the central equation of quantum mechanics. For an explanation for how we can describe a mechanical system in a way analogous to light waves, I suggest you check out this excellent video by Abide by Reason.

Example: simple pendulum

To see the Hamilton-Jacobi equation in action, let us apply it to the simple pendulum. Replacing \(p_{\theta}\) with \(\dfrac{\partial S}{\partial \theta}\):

\[\begin{aligned} H &= \dfrac{\left(\dfrac{\partial S}{\partial \theta}\right)^2}{2ml^2}+mgl\sin{\theta}. \end{aligned}\]

Substituting into Equation (95) yields:

\[\begin{aligned} \dfrac{\left(\dfrac{\partial S}{\partial \theta}\right)^2}{2ml^2}+mgl\sin{\theta} + \dfrac{\partial S}{\partial t} &= 0. \end{aligned}\]

Substituting Equation (96) yields:

\[\begin{aligned} \dfrac{\left(\dfrac{dW}{d\theta}\right)^2}{2ml^2}+mgl\sin{\theta} -E &= 0. \end{aligned}\]

Multiplying both sides by \(2ml^2\):

\[\begin{aligned} \left(\dfrac{dW}{d\theta}\right)^2 + 2m^2gl^3\sin{\theta}-2ml^2E &=0. \end{aligned}\]

Rearranging yields:

\[\begin{aligned} \left(\dfrac{dW}{d\theta}\right)^2 &= 2ml^2E - 2m^2gl^3\sin{\theta}. \end{aligned}\]

Square-rooting both sides yields:

\[\begin{aligned} \dfrac{dW}{d\theta} &= \pm\sqrt{2ml^2E-2m^2gl^3\sin{\theta}} \\ &= \pm \sqrt{2ml^2(E-mgl\sin{\theta})}. \end{aligned}\]

Integrating yields:

\[\begin{aligned} W(\theta) &= \pm\sqrt{2m}l \int \sqrt{E-mgl\sin{\theta}} d\theta. \end{aligned}\]

Next, we assume \(\dfrac{\partial S}{\partial E}\) will equal a constant, say \(\beta\). Then we differentiate Equation (96):

\[\begin{aligned} \dfrac{\partial W}{\partial E} - t &= \beta. \end{aligned}\]

Rearranging yields:

\[\begin{aligned} t+\beta &= \dfrac{\partial W}{\partial E}. \end{aligned}\]

Hence:

\[\begin{aligned} t+\beta &= \pm \sqrt{2m}l\int \dfrac{1}{2\sqrt{E-mgl\sin{\theta}}} d\theta \\ &= \pm \int \sqrt{\dfrac{ml^2}{2(E-mgl\sin{\theta})}} d\theta. \end{aligned}\]
The integrand — given it is integrated with respect to \(\theta\) to obtain \(t\) (plus some constant) — must be \(\dfrac{dt}{d\theta}\) which is one over \(\dfrac{d\theta}{dt}\) or \(\dot{\theta}\). Therefore:

\[\begin{aligned} \dfrac{dt}{d\theta} &= \pm \sqrt{\dfrac{ml^2}{2(E-mgl\sin{\theta})}}. \end{aligned}\]

Hence \(\dot{\theta}\) is:

\[\begin{align} \dot{\theta} &= \pm \sqrt{\dfrac{2(E-mgl\sin{\theta})}{ml^2}}. \tag{97} \end{align}\]

Squaring Equation (97) yields:

\[\begin{align} \dot{\theta}^2 &= \dfrac{2(E-mgl\sin{\theta})}{ml^2}. \tag{98} \end{align}\]
Differentiating the left-hand side of Equation (98) with respect to \(\theta\):
\[\begin{align} \dfrac{d\dot{\theta}^2}{d\theta} &= 2\dot{\theta}\dfrac{d\dot{\theta}}{d\theta} \notag \\ &= 2\dfrac{d\dot{\theta}}{d\theta}\dfrac{d\theta}{dt} \notag \\ &= 2\dfrac{d\dot{\theta}}{dt} \notag \\ &= 2\ddot{\theta}. \tag{99} \end{align}\]
Differentiating the right-hand side of Equation (98) and equating to the right-hand side of Equation (99) yields:
\[\begin{align} 2\ddot{\theta} &= -\dfrac{-2mgl\cos{\theta}}{ml^2} \notag \\ &= \dfrac{-2g\cos{\theta}}{l}. \notag \end{align}\]
Dividing both sides by \(2\) yields:
\[\begin{align} \ddot{\theta} &= -\dfrac{g}{l}\cos{\theta}. \notag \end{align}\]
Which we can see matches Equation (29).

Connections to other branches of physics

Classical mechanics provides the foundation that other fields of physics build on.

For instance, special relativity provides corrections (often called relativistic corrections) to classical mechanics to account for effects that become pronounced at speeds comparable to \(c\), the speed of light in a vacuum. General relativity accounts for these effects, too, but also accounts for effects most noticeable in strong gravitational fields.

Quantum mechanics instead focuses on what happens on small scales, namely the scale of atoms and subatomic particles. Like classical mechanics, quantum mechanics does not account for effects that become pronounced at speeds comparable to \(c\).

Quantum field theory focuses on quantum fields, such as those pertaining to electromagnetism, the strong nuclear force and the weak nuclear force. It also has the distinction of being relativistic — that is, it accounts for effects that become pronounced at speeds comparable to \(c\).

Special relativity

As previously mentioned, in special relativity we can make relativistic corrections to kinetic energy in our Lagrangian and Hamiltonians. Namely, we can define it as:

\[\begin{aligned} T(v) &= \dfrac{mc^2}{\sqrt{1-\dfrac{v^2}{c^2}}} - mc^2 \\ &= mc^2\left(\dfrac{1}{\sqrt{1-\dfrac{v^2}{c^2}}}-1\right). \end{aligned}\]

Classical limit of special relativity's kinetic energy

Using the Maclaurin series, we are going to show that \(T(v)\) is well approximated by \(T=\dfrac{mv^2}{2}\) when \(v << c\). To make things simpler for ourselves, we will consider the Maclaurin series of the function:

\[\begin{aligned} f(x) &= \dfrac{1}{\sqrt{1-x}} \\ &= (1-x)^{-1/2}. \end{aligned}\]

(This is as opposed to directly calculating the Maclaurin series of our \(T(v)\). If we directly applied the Maclaurin series formula to \(T(v)\) the derivatives we would need to calculate would get a bit unruly.) In this case:

\[\begin{aligned} f'(x) &= -\dfrac{1}{2}(1-x)^{-3/2} \cdot -1 \\ &= \dfrac{(1-x)^{-3/2}}{2} \\ f''(x) &= -\dfrac{3(1-x)^{-5/2}}{4} \cdot -1 \\ &= \dfrac{3(1-x)^{-5/2}}{4} \\ f^{(3)}(x) &= -\dfrac{15(1-x)^{-7/2}}{8} \cdot -1 \\ &= \dfrac{15(1-x)^{-7/2}}{8} \end{aligned}\]
Where \(f^{(3)}(x)\) denotes the 3rd derivative of \(f\) with respect to \(x\). Note how for the first derivative the coefficient is just \(\dfrac{1}{2}\), for the second derivative it is \(\dfrac{3}{4}\) and for the third it is \(\dfrac{15}{8}\). Seems to me that the denominator is just \(2^n\) where \(n\) is the order of the derivative and the numerator of the coefficient is \((2n-1) \times (2n-3) \times (2n-5)\times ... \times 1\). Hence:
\[\begin{aligned} \dfrac{d^nf}{dx^n} &= \dfrac{\left(\displaystyle \prod_{i=1}^n 2i-1\right)(1-x)^{-(2n+1)/2}}{2^{n}} \hspace{0.1cm}\forall n\in \mathbb{Z}^{+}. \end{aligned}\]
If you need an explanation of the product notation (\(\displaystyle \prod_{i=1}^{n} 2i-1\)) we used here, see the Product notation section.

Substituting in \(x=0\) into \(f(x)\) and our derivatives yields:

\[\begin{aligned} f(0) &= 1 \\ f'(0) &= \dfrac{1}{2} \\ \dfrac{d^nf}{dx^n}\Big|_{x=0} &= \dfrac{\displaystyle \prod_{i=1}^n 2i-1}{2^{n}}. \end{aligned}\]

In this case, \(x=\dfrac{v^2}{c^2}\), and we need to multiply by \(mc^2\) and subtract \(mc^2\) to obtain a Maclaurin series for \(T(v)\) and hence:

\[\begin{aligned} T(v) &= mc^2 \left(1 + \sum_{n=1}^{\infty} \dfrac{\left(\displaystyle \prod_{i=1}^n 2i-1\right)\left(\dfrac{v^2}{c^2}\right)^n}{2^{n}n!}-1\right) \\ &= mc^2 \sum_{n=1}^{\infty} \dfrac{\left(\displaystyle \prod_{i=1}^n 2i-1\right)\left(\dfrac{v^2}{c^2}\right)^n}{2^{n}n!}. \end{aligned}\]
Hence the first few terms of our Maclaurin series are:
\[\begin{aligned} T(v) &= mc^2 \left(\dfrac{v^2}{2c^2}+\dfrac{3v^4}{8c^4}+\dfrac{15v^6}{48c^6}+\dots\right) \\ &= \dfrac{mv^2}{2} + \dfrac{3mv^4}{8c^2} + \dfrac{15mv^6}{48c^4} + \dots. \end{aligned}\]
So what happens when \(v\) is much smaller than \(c\)? Well, we would expect every term with a non-zero power of \(c\) in the denominator to be negligible in its contribution to \(T\) and this leaves only the first term. Hence we obtain that for \(v << c\):
\[\begin{aligned} T(v) &\approx \dfrac{mv^2}{2}. \end{aligned}\]

General relativity

In general relativity, we can use the Einstein-Hilbert action to derive the Einstein field equations (EFE). The EFE are a series of partial differential equations that can be used to calculate the components of the metric tensor, \(g_{\mu\nu}\). The metric tensor is a type of matrix with sixteen total components that allow us to define proper time in curved spacetime. It has sixteen components because \(\mu\) and \(\nu\) can take on four different values each, corresponding to the four dimensions of spacetime (e.g. in Cartesian coordinates they are \(t\), \(x\), \(y\) and \(z\)), so that gives us \(4\times 4=16\) combinations of possible \(\mu\) and \(\nu\) values. Proper time is analogous to distance in spacetime and is the time that passes locally for an observer.

I should mention, in case you are unfamiliar, that in relativity, the passage of time itself is relative. Objects travelling close to the speed of light or in powerful gravitational fields have time pass substantially slower for them than those at lower velocities and in weaker gravitational fields.

The Einstein-Hilbert action is:

\[\begin{align} S &= \dfrac{c^4}{16\pi G} \int_{\mathbb{R}^4} R \sqrt{\left|\det{g_{\mu\nu}}\right|} d^4 x. \tag{100} \end{align}\]
One major difference you may notice between the classical action and the Einstein-Hilbert action is that the classical action is integrated over time whereas the Einstein-Hilbert action is integrated over spacetime (that is what the \(d^4x\) and \(\mathbb{R}^4\) are about). \(R\) is the Ricci scalar which is calculated based on \(g_{\mu\nu}\) and \(\det{g_{\mu\nu}}\) is the determinant of the metric tensor matrix.

Another application of action in general relativity is that it can be used to calculate the path an object will take in curved spacetime. As the path the object follows will be the path that maximizes its proper time. The action for this calculation is:

\[\begin{align} S &= -mc \int_{\lambda_0}^{\lambda_f} \sqrt{\Big| g_{\mu\nu} \dfrac{dx^{\mu}}{d\lambda} \dfrac{dx^{\nu}}{d\lambda}\Big|}d\lambda. \tag{101} \end{align}\]

Why the \(-mc\) coefficient? Well, the negative sign is to ensure that minimizing \(S\) corresponds to maximizing the proper time. As for the \(mc\), it is to get our units right. See the integral itself is in units of metres. \(m\) is in units of kilograms and \(c\) is in units of metres per second. Consequently our units overall are \(\mathrm{kg} \cdot \mathrm{m}^2 \cdot \mathrm{s}^{-1}\). Action is in units of \(\mathrm{J}\cdot \mathrm{s}\), where \(\mathrm{J}\) denotes Joules, the SI standard units of energy. Joules are, in turn, defined as \(\mathrm{kg}\cdot \mathrm{m}^2 \cdot \mathrm{s}^{-2}\). So \(\mathrm{J}\cdot \mathrm{s}\) is \(\mathrm{kg}\cdot \mathrm{m}^2 \cdot \mathrm{s}^{-1}\), which matches the units of our \(S\). I should also explain that in this integral, \(\lambda\) is an arbitrary parameter. Often we choose it to be proper time. Setting \(\delta S=0\) yields the geodesic equations which are a series of ordinary differential equations that maximize proper time.

Quantum mechanics

We have seen in this article that there are multiple different formulations of classical mechanics. Similarly, there are multiple different formulations of quantum mechanics.

Path-integral formulation

One formulation of quantum mechanics is the path-integral formulation developed by Richard Feynmann. In it, we expect our particle or wave to explore all possible paths and we integrate (or sum) over all those paths in order to compute the probability amplitude of our particle. The exploration of all possible paths is a consequence of the randomness of quantum mechanics. Specifically, we compute the integral:

\[\begin{align} K(\mathbf{x}_f, t_f; \mathbf{x}_0, t_0) &= \int_{\mathbf{x}(t_0)=\mathbf{x}_0}^{\mathbf{x}(t_f)=\mathbf{x}_f} e^{\frac{iS(\mathbf{x})}{\hbar}} \mathcal{D}\mathbf{x}. \tag{102} \end{align}\]

Where \(K\) is the propagator, which specifies the probability amplitude for travelling from \(\mathbf{x}_0\) at time \(t_0\) to \(\mathbf{x}_f\) at time \(t_f\). \(S\) is the action of the particle, \(\hbar\) is the reduced Planck's constant, \(i\) is the imaginary number and \(\mathcal{D}\mathbf{x}\) refers to the fact we are integrating over all possible paths. The probability amplitude is a quantity that, if you take the absolute value of, and square this quantity you get the probability of the particle travelling from \(\mathbf{x}_0\) at time \(t_0\) to \(\mathbf{x}_f\) at time \(t_f\).

One major strength of the path-integral formulation of quantum mechanics is that it provides an explanation for how quantum mechanics gives rise to classical mechanics on larger scales.

So, with the background information covered in Prerequisite mathematics in mind, we now know that \(e^{\frac{iS}{\hbar}}\) is like a 2D unit vector as it points in particular direction in the \(xy\) plane and has unit length. Specifically, it points in the direction \(\dfrac{S}{\hbar}\) radians counterclockwise from the positive \(x\) axis. Each integer multiple of \(2\pi\), which corresponds to a complete revolution around the Cartesian plane, that is present in \(\dfrac{S}{\hbar}\) makes no difference to its overall direction. What matters is what is left after subtracting these integer multiples of \(2\pi\).

Interestingly, when we integrate over all possible paths on classical mechanics scales we find that the \(e^{\frac{iS}{\hbar}}\), for most paths, cancel each other out. To see why, we must first start with the fact that \(\hbar\) is a very tiny number — it is approximately \(1.055\times 10^{-34}\mathrm{J}\cdot \mathrm{s}\). Consequently, \(\dfrac{S}{\hbar}\) is a massive number when we are analysing classical mechanical systems. As typically in these scenarios \(S\) is \(\gt0.01\mathrm{J}\cdot \mathrm{s}\). As a result, even a relatively small difference in \(S\) can lead to a majorly different direction for \(e^{\frac{iS}{\hbar}}\).

This leads to the actions of nearby paths often being in opposite directions and cancelling each other when we calculate the path integral. The one exception is the path corresponding to the stationary action. Remember the equation \(\delta S=0\) that we solve to find the path of our classical mechanical system? It says that a tiny change to the stationary action path should make no change (to first order) to the action and consequently, when we integrate \(e^{\frac{iS}{\hbar}}\) for that path and its neighbours, the stationary action path term is the only one that survives. Consequently, in the classical limit our object only explores the path that extremizes the action, and as we have seen an extremized action leads to the equations of motion in classical mechanics.

Operator formalism

Another connection between what we have covered and quantum mechanics is in the operator formalism of quantum mechanics. In it, we represent the state of our physical system using a function called the wavefunction which is denoted as \(\psi\), which can also thought of as a vector, as it is a complex number. We can calculate the wavefunction using Schrödinger's equation:

\[\begin{align} i\hbar \dfrac{\partial \psi}{\partial t} &= \left(-\dfrac{\hbar^2}{2m}\Delta + V(\mathbf{x})\right)\psi. \tag{103} \end{align}\]

\(V(\mathbf{x})\) is the potential energy and \(\Delta\) is the Laplacian which is essentially just \(\dfrac{\partial^2}{\partial x^2} + \dfrac{\partial^2}{\partial y^2}+\dfrac{\partial^2}{\partial z^2}\). The right-hand side of Equation (103) can also be represented by \(\hat{H}\psi\) where \(\hat{H}\) is the Hamiltonian operator and calculates, from the wavefunction, the total energy of our system. Another important link to classical mechanics that I have already alluded to is that Schrödinger's equation was derived using the Hamilton-Jacobi equation. Specifically, Schrödinger used the Hamilton-Jacobi equation to derive an action that he then extremized and out from that popped his equation.

Quantum field theory

Lagrangians, Hamiltonians and actions also appear in quantum field theory, including The Standard Model of particle physics. In fact, if you want to see a dauntingly long and complex Lagrangian, Google The Standard Model Lagrangian.
