Mathematical solver pages

An attempt was made to create a 1D heat equation numerical solver webpage and add it to the below list. This attempt was abandoned, however, as it seems it is too computationally expensive for a webpage. The numerical integration technique I attempted involved approximating spatial derivatives from grid point values using fast Fourier transforms (and their inverse) and integrating on time using the Runge-Kutta-Fehlberg 4/5th-order method (RKF45).
